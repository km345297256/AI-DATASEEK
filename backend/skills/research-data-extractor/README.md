# 科研数据抽取专家技能

## 概述

本技能用于从《国家重点研发项目任务书》PDF中提取考核指标、课题研究内容，并生成符合《科学数据汇交计划》规范的"科学数据资源清单"。

## 功能特性

- **PDF章节精准截取**：按照标准章节标识符自动截取PDF特定内容
- **考核指标智能识别**：自动识别KPI中的量化要求与技术产出
- **研究内容深度分析**：根据研究内容推导其底层支撑数据
- **合规清单自动生成**：严格遵循《科学数据汇交计划》的命名与编号规范

## 使用方法

### 方式一：通过Claude技能直接调用

当您上传一个项目任务书PDF文件时，直接告诉Claude：

```
"请帮我处理这个项目任务书PDF，提取考核指标和课题研究内容，生成科学数据资源清单。"
```

Claude将自动：

1. 抽取考核指标并保存为txt文件
2. 抽取课题研究内容并保存为txt文件
3. 分析内容并生成数据资源清单Markdown文件

### 方式二：使用Python脚本

#### 步骤1：抽取PDF文本

```bash
python scripts/pdf_text_extractor.py <PDF文件路径> <输出目录>
```

示例：

```bash
python scripts/pdf_text_extractor.py 项目任务书.pdf ./output
```

输出文件：

- `output/项目任务书_考核指标.txt`
- `output/项目任务书_课题研究内容.txt`

#### 步骤2：生成数据清单

```bash
python scripts/data_inventory_generator.py <考核指标文件> <课题研究内容文件> <输出文件路径>
```

示例：

```bash
python scripts/data_inventory_generator.py \
    output/项目任务书_考核指标.txt \
    output/项目任务书_课题研究内容.txt \
    output/科学数据资源清单.md
```

## 章节截取规则

### 考核指标截取

- **起始标识**：`一、项目` 及其变体
- **结束标识**：`备注：` 及其变体

### 课题研究内容截取

- **起始标识**：`二、项目` / `二、课题` 及其变体
- **结束标识**：`五、预期` 及其变体

## 数据清单生成逻辑

### 1. 考核指标解析

系统从考核指标中识别以下要素：

| 要素类型 | 识别规则                     | 示例              |
| ---- | ------------------------ | --------------- |
| 量化指标 | 包含数字+单位的表述               | "完成不少于50个样本的采集" |
| 技术产出 | "形成"/"建立"/"开发"/"研制"等动词引导 | "形成一套评价方法体系"    |
| 成果形式 | 论文、专利、软件、数据库、标准等         | "发表SCI论文3篇"     |
| 时间节点 | 年份、季度、月份等时间标识            | "2026年底前完成"     |

### 2. 研究内容推演

根据课题研究内容，系统推导其产生的数据类型：

| 研究活动 | 推导数据类型 | 数据示例             |
| ---- | ------ | ---------------- |
| 实验研究 | 原始实验数据 | 实验参数、测量值、观测记录    |
| 仿真模拟 | 仿真模拟数据 | 模型配置、仿真结果、可视化数据  |
| 调查研究 | 调查统计数据 | 问卷数据、统计报表、抽样数据   |
| 软件开发 | 软件工具   | 程序代码、测试用例、日志数据   |
| 文献研究 | 文献资料数据 | 文献信息、引文网络、知识抽取结果 |

### 3. 数据条目字段

每个数据条目包含以下字段：

- **序号**：按数据产生的逻辑顺序编号
- **数据资源名称**：规范命名格式 `[研究对象]_[数据类型]_[时间/阶段标识]`
- **数据类型**：原始实验数据/观测监测数据/调查统计数据/仿真模拟数据/文献资料数据/软件工具/标准规范/其他
- **数据格式**：实际文件格式（.xlsx/.csv/.txt/.pdf等）
- **数据量**：根据考核指标中的量化要求估算
- **产生阶段**：对应项目执行的时间节点
- **汇交方式**：离线汇交/在线汇交/接口汇交
- **开放属性**：完全开放/受控开放/暂不开放
- **备注**：数据来源说明

## 注意事项

1. **章节标识变体处理**：系统使用模糊匹配策略处理各种变体，如"一、 项目"（带空格）、"（一）项目"（带括号）等。

2. **数据量估算原则**：
   
   - 优先使用考核指标中的明确量化数据
   - 无明确数据时，根据研究内容合理估算
   - 在备注中说明估算依据

3. **命名规范遵循**：
   
   - 严格遵循《科学数据汇交计划》的命名规范
   - 使用简洁、明确、无歧义的命名
   - 避免使用特殊字符和空格

4. **质量控制**：
   
   - 生成的每个数据条目都应有明确的来源依据
   - 数据类型和格式应与研究内容匹配
   - 汇交方式和开放属性应符合项目实际情况
