# Code Change

Use this skill when changing code in a repository.

Read the nearby code before editing. Prefer the project's existing patterns, helper APIs, directory boundaries, and naming conventions. Keep changes scoped to the requested behavior and avoid unrelated refactors.

When adding behavior, update or add focused tests when the risk justifies it. If tests cannot be run, explain why and describe the next best verification performed.

Before finishing, review the diff for accidental broad changes, generated file churn, secret exposure, and broken imports.
