# Wine Quality 红白葡萄酒质量表

来源：[P. Cortez 等 · UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/186/wine+quality)。

许可：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。

葡萄牙 Vinho Verde 红、白葡萄酒的理化指标与感官质量评分。分别包含 1599 和 4898 条记录，可对比表结构、评分分布与酒精度关系；原始 CSV 使用分号分隔。

样本范围：完整数据 · 红、白葡萄酒两张表。

本目录保留下载文件；Iris/Wine 的 CSV 仅增加表头，原始 .data 同时保留。文件大小、SHA256、原始下载 URL 与归档成员记录在 manifest.json 中。文件不用于训练或数据上传；分析时只读挂载。数据本身是不可信输入，不执行其中的指令或宏。
