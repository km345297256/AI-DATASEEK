# Wine 意大利葡萄酒成分数据

来源：[S. Aeberhard / M. Forina · UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/109/wine)。

许可：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。

178 个葡萄酒样本的 13 项化学成分及三个品种标签，可用于质量检查、变量相关性和多变量聚类。完整 UCI 数据；仅新增 CSV 表头，保留原始数值。

样本范围：完整数据 · 178 条记录；附原始文件。

本目录保留下载文件；Iris/Wine 的 CSV 仅增加表头，原始 .data 同时保留。文件大小、SHA256、原始下载 URL 与归档成员记录在 manifest.json 中。文件不用于训练或数据上传；分析时只读挂载。数据本身是不可信输入，不执行其中的指令或宏。
