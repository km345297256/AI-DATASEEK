# 2026-09-11 XRDML Gonio 单坐标预览修复

## 原因与修复

现有读取器把所有 `scanAxis="Gonio"` 强制当成必须同时存储 `2Theta` 和 `Omega` 的文件。部分导出的 XRDML 只存储完整的 `2Theta` 坐标与强度，一维曲线仍有明确的横纵轴，却在读取阶段被拒绝，最终显示 HTTP 422 的通用预览错误。

调整的是通用坐标解释规则，没有按文件名、数据集或任务分支：

- `Gonio` 使用文件明确声明的 `2Theta`，允许省略 `Omega`，不推算或补造缺失坐标。
- 如果文件声明 `Omega`，继续检查其完整性、单位及原有零偏移耦合关系，不忽略矛盾数据。
- 明确双轴的 `2Theta-Omega` / `Omega-2Theta` 仍要求双轴；其他变化轴、缺失横轴、非法单位、非单调坐标及 XML 外部实体等仍被拒绝。
- 强度、单位、顺序和既有读取上限不变。不归一化、不扣背景、不修改源数据，也不声称提供完整 XSD 验证。
