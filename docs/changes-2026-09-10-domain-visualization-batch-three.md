# 科学领域扩展第三批：深入实验数据

日期：2026-09-10。新增四个可独立启停的 Cordis 插件，目录由 56 增至 **60 个插件、59 个批准适配器**。

## 本批能力

在[可视化插件管理](http://localhost:7001/plugins?tab=renderers)中启停，再从数据文件预览的视图菜单选择。

| 插件 | 支持的首版能力 | 明确边界 |
| --- | --- | --- |
| `viz-mass-spectrum` | MGF、受限 mzML 的分页谱目录；centroid 棒谱、profile 曲线 | 16 MiB 整文件输入；每谱最多 16,384 对值，明确单位及时间声明；不是完整 mzML 工具箱 |
| `viz-fcs-window` | FCS 3.0/3.1 通道目录、事件窗散点与直方图 | 原始事件值；不自动补偿、logicle 变换、gating 或校准；不支持多数据集/补充 TEXT |
| `viz-diffraction` | 受限 XRDML 扫描、canSAS1d XML 的 Q-I 曲线和已声明误差条 | 非等步长保留；不自动拟合、扣背景或按计数时间归一；误差声明不擅自解释为标准差 |
| `viz-ripple-window` | Ripple 三维 vector 谱像的单通道区域与像元能谱 | 精确登记 `.rpl + .raw`；保留空间/能量标定与负尺度；不是全量 HyperSpy 或仪器专有格式支持 |

详细规范：[质谱](mass-spectrum-format.md)、[流式](fcs-window-formats.md)、[衍射/散射](diffraction-formats.md)、[电子显微谱像](ripple-window-format.md)。

## 协议、兼容与效率

- 继续使用公有契约 2、原来的统一预览入口和已有 tree/array/series 结果类型。插件清单同步生成三端批准映射，并由真实 Cordis 生命周期管理。
- AgentLoop、PlanActFlow、SSE、FastAPI 主机和 Docker 数据只读隔离不变。不新增模型调用、分析作业或凭据权限。
- 所有新插件只授予 `file:read`、`shared:false`、`preview`；拒绝原始字节、准备作业、任意路径/URL和写入能力。
- 数值选择必须由客户端携带结构目录版本；质谱非首目录页也绑定版本。旧文件或停用插件的结果不能继续绘图。
- Ripple 配对共同版本和最终校验覆盖两成员，不因只读头文件而漏检原始数据变化；没有授予任意同目录读取能力。
- 原稳定插件 ID、启停偏好和默认优先级保持。新的通用 `.xml` 衍射候选优先级低于原结构树，不抢占 XML 默认视图。
- 图形复用现有本地 Plotly，按需加载；切换文件/插件/参数会取消旧请求，卸载时释放图形和监听器。没有新增生产依赖。

### 如实区分读取量

| 读取器 | 实际预算与语义 |
| --- | --- |
| 质谱 | 每次读取 ≤16 MiB 整文件、最多 1024 谱、每页 64 谱；选定谱最多 16,384 对数值。只有此契约允许 32,768 标量，旧数组仍为 16,384 |
| 衍射/散射 | 每次解析 ≤16 MiB XML；最多 32 扫描、每扫描 16,384 点、文件总点数 65,536。选一条曲线不冒充只解析这一条 |
| 流式 | 源 ≤8 GiB、累计 ≤8 MiB/128 次范围读取；头部 58 B、TEXT ≤256 KiB；最多 128 通道，单次 ≤8192 事件/16384 输出值。窗口读取完整选定事件行，未选通道字节也计费 |
| Ripple | 精确双文件源 ≤8 GiB、累计 ≤8 MiB/256 次；图像 ≤128²、能谱 ≤16384 通道；目录仅头文件，真实 raw 窗口，合并跨度也计入读取量 |

四类结果均 ≤2 MiB。拒绝不支持方言/编码和超预算请求，不隐式全量读取或静默抽样。预算不是固定加速倍数或完整进程 RSS 承诺。
