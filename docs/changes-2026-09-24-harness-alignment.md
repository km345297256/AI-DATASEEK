## 已实施的六项

1. **调用身份与请求隔离**：完整解析后、保存及派发前校验整批工具调用 ID，重复/非法 ID 走现有有限模型纠错；缺失 ID 在独立副本中统一补齐。历史兼容只生成深拷贝请求，不改写持久历史；缺失结果、重复/冲突身份显式 unknown/error，不构造成功证据、不自动重跑。历史观察不静默丢弃。动态 system/user 上下文和 MCP 图片仅属于实际请求。
2. **Shell 输出保护**：32 KiB UTF-8 安全预览；console 总量 128 KiB/64 条；每个输出世代拥有不含路径的 output_id。私有匿名临时文件保存清洁/原始流，每流 32 MiB 上限，失败或超限明确标注且不终止任务。调用者自持游标，模型与页面观察不会互相消耗；每页最多 16 KiB，旧命令游标不能读新命令。日志在沙箱进程/命令生命周期内可用，并非跨重启永久日志。确定性科学工具/插件在原有大小契约内只读补齐 stdout 再解析，不重复执行。
3. **提交确认**：普通输入在会话控制器内保存固定请求 ID、时间戳和载荷；明确拒绝与连接结果未知分开。新增 owner-only 只读接收核对接口，只返回 accepted、event_seq、state。未观察不代表拒绝，同一次恢复保持原 ID；有意新输入使用新 ID，不按文本去重。现有提示位置支持恢复，不新增布局；草稿和附件不会因未确认提交静默丢失。待确认载荷仅保留在内存，不写浏览器存储。
4. **长会话索引与阅读位置**：新增会话私有工具/当前轮次步骤索引和增量展示摘要索引，历史前插后重建索引、实时追加只处理后缀。保留组件、稳定消息 key、折叠和附件顺序，不改为虚拟列表。历史阅读以消息 key/偏移保持位置，处理迟到布局变化，读者主动滚动后释放锚点，切换/卸载清理观察器。
5. **持久格式门禁**：冻结六个持久化根的读写 Schema 与版本，比较共享类型变化；每次变更追加快照并逐根说明兼容性与迁移测试，破坏性变化要求实际写入版本增加。包含旧数据回读、事件回放、私有字段隔离和旧执行缓存失效测试。检查接入统一回归与 pytest。详见 `docs/persistence/README.md`。
6. **可选 MCP 图片**：按 MIME、base64、帧数、尺寸和现有图片规则校验，规范化后存入 owner/session 隔离的私有 spill；只在请求前重新授权并展开图片，事件与记忆不含 base64 或内部 file_id。图文预算在结果策略之后执行，策略删除的图片不能恢复；缺失/过期/撤权不退回原始图片。受治理的图片恢复工具与第三方 MCP 命名隔离。详见 `docs/mcp-image-results.md`。

## 配置与安全边界

- MCP 图片通过 `MCP_IMAGE_RESULTS_ENABLED=true` 显式启用，同时要求 spill 可用及实际模型已声明支持图片。默认关闭以兼容原文字工具；不会擅自换模型、接口或密钥。未知/不支持图片的模型明确省略图片，不承诺自动保存这类初始回包供未来换模型读取。
- 上述限制都是缓冲、单次读取/请求或临时日志存储保护，不是任务累计次数、Token 或时长配额。
- 不添加归档/提醒/作业控制台等产品域；不将 MCP 内容、原始输出或传输完成状态当作科学成功或执行授权。
- 不改 Compose、端口、DATASET_HOST_PATH_ALLOWLIST 或数据集只读边界；真实宿主机路径不得进入浏览器存储或公开响应。
- 初始实施阶段未部署、未提交/推送、未执行真实模型或用户数据分析，验证使用合成数据、模拟模型或隔离测试环境。后续用户授权的图片启用与实际部署见文末追加记录。
