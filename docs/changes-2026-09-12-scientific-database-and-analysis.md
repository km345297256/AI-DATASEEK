# 科学数据可视化、数据库文件探查与分析可靠性更新

日期：2026-09-12。目标分支：`v2`。对比基线：`02f2fcd0a15b29b17594a8ded9be36828f19371e`。

本说明汇总该基线之后尚未提交的代码、测试、合成样本和配套文档。它是本次提交说明，不是新的部署记录；本次检查未更新服务、读取业务数据集或调用真实模型。

## 1. Cordis 可视化能力扩展

- 可视化插件从 36 个增至 **81 个**，批准适配器从 35 个增至 **76 个**；继续使用 `contract_version: 2`。
- `contracts/visualization-adapters.json` 继续作为唯一规范来源，同步生成前端、后端与 Cordis host 的映射，并校验生成副本一致性。
- 增加结构树、压缩包目录及成员、数组和信号窗口、列式数据、NeXus、科学网络、系统发育树、质谱、衍射等预览。
- 扩展 ENVI、GRIB、地震、雷达、海洋网格、点云、DICOM、空间组学、流式细胞、仪器图像、显微图像、模拟网格、分子轨迹等领域能力；具体格式、编码与大小限制以各格式文档为准，不代表支持相关标准的全部变体。
- 保留旧插件，按用途允许同一文件选择多个视图；完善格式匹配、默认选择、内容探测及插件目录展示。

### 迁入 main 的已有工作台

在现有 Cordis 架构内增加矩阵、天文图像、比对、序列、基因组轨道和 BLAST 六个工作台。迁移使用现有统一预览接口与受信适配器，不整体合并 main，也不引入旧主机缓存、任意组件加载或另一套插件管理器。

这些工作台提供切片、窗口、区域选择、轨道、覆盖度、质量值及结果详情等交互。whole 模式仍是受大小预算约束的完整快照，不冒充超大文件的索引读取服务。

## 2. 数据库文件只读探查

| 类型 | 新增能力与限制 |
| --- | --- |
| SQLite、DuckDB、DBF、Access | 支持范围内的目录、字段、选列和分页；Access 不执行 VBA、查询或跟随链接表 |
| SQL dump | 受限声明和字面量记录预览，不执行 SQL |
| PostgreSQL dump | 受支持归档的 TOC 目录探查，不恢复备份，不将目录冒充完整数据预览 |
| BSON、Redis RDB | 受支持记录的有界树形探查，不连接数据库、不启动恢复流程 |

精确整数和定点小数以文本保真传输，区分 NULL、空串、布尔值、二进制摘要、缺失字段和非有限数值；不隐式把高精度值转换成 JavaScript 浮点数。当前页图表只使用允许安全绘制的已返回值，并说明排除项。

新增严格的前后端载荷校验、数据库原生读取器、Access 专用有界原生适配层，以及 BSON Decimal128 对照样本。未知版本、加密、复杂对象或超预算内容明确拒绝，不静默修复或加载外部依赖。

## 3. 分析执行与交付可靠性

- 识别模型把工具调用写成普通文本的协议错误；通过原有工具循环进行有界纠正，**不会从回复文本解析参数后直接执行工具**。
- 纠正前协调已有执行账本；对未确认执行、无进展及不合法终态明确停止，避免重复执行或无证据宣称成功。
- 终态 JSON 只做本地语法解码，取消工具关闭后另调用模型补造结果的路径；需要纠正时回到仍有工具范围和账本约束的原循环。
- 加强终态执行结果和产物证据校验，增加 `missing_artifact` 原因及其受限补交处理。
- 重试时清理旧步骤结果与附件；补交期间抑制未经核验的草稿及重复消息，后续总结不能把未完成步骤重新描述为成功。
- 同步前端失败原因、后端交付判定和沙箱产物检查，新增对应回归测试。

本批次确实调整了现有 Agent 循环内部的校验与纠正逻辑；保留 PlanActFlow、执行账本、既有 SSE 通信、FastAPI 主机和 Docker 隔离架构，没有替换成 Harness AgentLoop。

## 4. 兼容性、安全与效率

- 保留数据集路径 allowlist、只读挂载、所有者鉴权、私有产物、文件版本及插件 revision 校验；浏览器使用不透明文件标识，不暴露宿主真实路径。
- 原生格式解析仍在隔离 worker 中进行，按读取器限制输入、输出、时间与资源；不把数据库引擎加载进后端主机，也不向解析器开放业务凭据或外部数据库。
- 完善受控共享文件及旁车文件读取，不能绕过原有数据集范围授权。
- 按窗口、页、选列读取和展示，惰性加载图表；切换文件、版本或视图时取消旧请求，忽略过期响应并释放资源。
- 修复等价配置刷新触发重复读取的问题，完善 Shapefile／OpenLayers 交互与已有科学预览生命周期。
- 效率收益来自减少无效读取、重复渲染和错误重试；本次没有进行业务数据性能基准，不提供未经测量的加速比例。whole 快照及部分顺序分页仍有明确规模限制。
