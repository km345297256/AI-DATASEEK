# 科学领域扩展第一批：列式大表、科学网络与 NeXus

日期：2026-09-10。实施顺序见[领域扩展路线](domain-visualization-expansion-roadmap.md)。

本批是新一轮领域扩展的第一批，不代表后续医学影像、空间组学、点云、仿真等候选已经实现。

## 新增能力

新增三个独立 Cordis 插件，目录由 49 增至 **52 个插件、51 个批准适配器**。

| 插件 | 用户可用能力 | 首版边界 |
| --- | --- | --- |
| `viz-columnar-window`：Parquet / Arrow 分块表格 | 先查看列类型和数据块概况，再选择列、行起点与分页；整数和 Decimal 保留精确文本 | 单文件 Parquet、Arrow IPC file / Feather v2；受限平面类型，不支持 IPC stream、分区目录、嵌套/扩展/时间/二进制类型或任意 SQL |
| `viz-scientific-graph`：科学关系网络 | 有向/无向拓扑、圆形/网格布局、节点搜索、节点与边详情 | 规范化网络 JSON、平面 GraphML、静态 GEXF 1.2/1.3；不等于任意 JSON 或 Cytoscape 完整会话格式 |
| `viz-nexus-window`：NeXus 科学坐标与误差 | 识别 NXdata 信号，显式选择窗口；曲线显示文件提供的坐标、单位与误差条，热图使用真实坐标 | HDF5 中现代 NXdata、1D/2D 数值信号、受限固定长度字符串元信息、同文件硬链接；不支持可变长属性、旧声明、边界坐标、多维轴、外链或自动标定 |

普通 JSON 仍默认结构树，NeXus 的原 H5Web、HDF5 原始数组和其他旧视图保持原优先级。停用其中一个视图不会关闭同格式的其他能力；已有个人开关状态不迁移、不重置。

## 如何使用

1. 在[本机插件页](http://localhost:7001/plugins?tab=renderers)搜索“Parquet”“科学关系网络”或“NeXus”，可独立启动/停止。
2. 在数据集探查页打开相应文件，在“可视化”下拉框切换到对应插件。
3. 列式大表先读元信息，选择列及行窗口后明确读取。分页继续绑定同一文件版本；不会自动加载整张表或做全量聚合。
4. NeXus 先选择已识别的信号和切片。无兼容信号时界面解释首版限制，可手动使用原 HDF5 视图；不会猜测信号、坐标或单位。详细格式见 [NXdata 支持边界](nexus-window-format.md)。
5. 网络图只读已提供的关系。布局、缩放、搜索不再次下载；边权重不自动解释为距离、显著性或因果强度。输入样例见[科学网络格式说明](scientific-network-format.md)。

## 协议适配

- 沿用严格整数 `contract_version: 2`、现有 `POST /files/{opaque_id}/visualization` 和 `APIResponse`；没有另一套可视化接口。
- 唯一批准规范增加三组 adapter/reader，生成 Node、Python、TypeScript 构建副本。新增明确的 `graph` 场景和结果类型，不把关系网络塞进文件树或地理 GeoJSON。
- 列式/NeXus 复用私有窗口代理，窗口选择必须携带初次目录的文件 `version`。宿主逐次核验身份、插件状态、目录代际、文件版本和实际读取预算。
- Python、worker 和前端分别验证新数据结构。图的端点、方向和计数，表格的列与行窗口，NXdata 的轴/误差形状及选择都绑定实际请求。
- 保留 AgentLoop、PlanActFlow、SSE、FastAPI 与 Docker 数据隔离；这些可视化不会进入模型工具列表，不创建会话、模型调用或隐式 AnalysisJob。
- 新增节点/坐标并不授予目录、任意文件、URL 或 SQL 权限。后续多文件插件仍须逐项定义精确的资源范围。

## 读取和计算预算

| 能力 | 主要限制 |
| --- | --- |
| 两类窗口读取 | 源 ≤8 GiB；每次实际累计读取 ≤8 MiB、≤128 次；单次范围 ≤1 MiB；输出 ≤2 MiB |
| 列式元信息 | ≤1 MiB、≤128 列；Parquet ≤1024 行组、Arrow IPC ≤64 批次 |
| 列式显示窗口 | ≤200 行×32 列；本次涉及的行组/批次累计 ≤262,144 行；不把输出行数当实际扫描量 |
| 列式解码 | 有界页/缓冲区预检与压缩一致性验证；单块 ≤4 MiB、展开预算 ≤16 MiB；不支持的布局失败关闭 |
| NXdata | 信号与误差/坐标合计 ≤16,384 值；单块 ≤4 MiB、选区涉及块展开 ≤16 MiB；仅明确坐标，未声明轴时才显示索引 |
| 网络图 | 源 ≤4 MiB、结果 ≤1 MiB、≤1000 节点/3000 边；不抽样伪装成完整图；有界本地布局 |

窗口和网络解析继续在无网络、无端口、无主机/数据集挂载、非 root、只读根文件系统的短命容器中运行；窗口与扩展 worker 保持既有资源限额与硬截止时间。不支持某种编码时不降级为 FastAPI 进程内解析或无限制整文件读取。

“分块读取”不保证任何输入都能低成本打开：巨大行组、异常压缩页、过多批次或复杂元信息仍会拒绝。页面显示实际取回字节和扫描量；不宣称固定倍数提速。PyArrow 是受控后端读取器，不是把数据库或整个数据文件搬到浏览器。

Parquet 按所选列块读取；Arrow IPC / Feather 当前读取并解码命中的整个数据批次，再选取所选列，并非物理列投影。16 MiB 是解码页/缓冲区预算，不是进程总内存：隔离 worker 仍受原有 1 GiB 内存硬限制。压缩预检增加一次有界解码成本，用来避免仅信任文件头中的展开长度。

## 依赖与测试入口

- Cytoscape.js `3.34.3` 固定版本、按适配器懒加载，无 CDN、图标 URL 或在线数据库请求。
- PyArrow `25.0.1` 从已存在的传递依赖提升为明确的直接依赖，版本不变；不引入 DuckDB、Arrow Flight、Qt 软件或新常驻服务。
- HDF5/NumPy/Plotly 复用已锁定依赖；NeXus 是对现有数组读取能力的语义增强。
- `backend/scripts/check_domain_visualization_http.py`：实际本机接口、8 个独立合成文件，覆盖新入口、显式版本、超限与恶意输入、关闭插件；按精确标记和 ID 清理，恢复偏好并核验业务元数据不变。
- `frontend/tests/browser/domains-smoke.mjs`：真实 Vue/Cytoscape/Plotly 渲染，合成响应由真实科学库生成；检查外联、过期响应与释放。
- 新增各层单测与旧系统完整回归；Cordis 测试逐一销毁新插件的真实 fiber，确认仅撤销该注册。
