# 统一分析、可信程序执行与交付审核更新

日期：2026-09-18；目标分支：`v2`。

本次新增提交以 `27b286ff38dbc5f60bebd77772bc01439622fac5` 为基线。提交前核实远端 `v2` 仍为 `9b95762`，因此推送同时包含上次因网络超时未上传的 `27b286f`；该提交的细节见 [9 月 15 日汇总](changes-2026-09-15-harness-reliability-and-benchmarks.md)。本文件说明其后的最新改动。

## 1. 统一分析入口和输入范围

- 保留 Chat 与数据集探查两个入口，抽取共用 `useAnalysisSession` 和 `AnalysisConversation`，统一发送、停止、续作、SSE 归并、断线恢复、历史分页、消息与成果展示。
- 新增分析资料面板及服务端 `AnalysisInputContext`，支持用户上传文件与已绑定数据集共同进入分析。仅上传文件也可提交明确的概览请求，未完成上传不能提交。
- `input_file_ids` 省略表示继承、空数组表示清空上传选择，当前附件追加到选择中；每轮受理后冻结输入快照并重新鉴权，运行中不允许后续选择改变既有任务。
- 输入原件和生成成果分开管理，生成文件不会自动变成下一轮资料。上传关联文件按来源分组，同名文件按身份消歧。
- 新增会话分析资料接口；续作核验原始身份、运行位置、大小、完整文件清单与指纹，拒绝伪造来源、越权、符号链接及源内容变化。数据集 allowlist 与只读挂载保留。

## 2. 程序执行真值与长任务

- 新增第一方 `program_run` 与沙箱程序接口，以固定解释器运行 Python 源码快照，参数为字面字符串列表；记录源码 SHA-256、退出码、诊断和私有执行回执，不用程序输出文字判断成功。
- 公开工具参数使用 `argv`，由可信适配器映射内部字段；调用前校验真实函数签名，明确区分启动前失败与可能已有副作用的错误。
- 已知保存的 Python 程序引导到专用执行器；其他语言保留原工具能力，不宣称任意 Shell 命令都拥有同等回执。
- 程序修订、失败诊断、前置条件检查与无进展保护绑定同一程序及真实终态。只有确认 `not_started` 且前置条件改变才允许恢复；状态未知、待确认或仅更改哈希不能触发自动重跑。
- 第一方长程序启动一次后分段观察同一操作，不因单次观察窗口结束而重复启动；租约续租、失租取消、用户取消和进程树清理仍有效。该策略不向普通工具或同名插件开放。
- 自定义 quicklook fallback 进入同一受控工具循环，保持目标与交付契约，删除旧的独立编译／整段固定重跑分支；补充 quicklook 和程序诊断回归。

## 3. 回答和成果的一致性

- 原始交付契约保留目标、类型、数量、格式及明确输出身份，不能以另一张图或同名不同路径的文件替代已承诺成果。
- 成功分支也进行独立、无工具的回答证据审核。草稿、保存的代码、文件存在本身都不等于分析已执行或科学结论已核验。
- 按段绑定实际证据、原文摘录、文件身份及执行状态；失败保留已验证文件和可核验段落，不直接发布未经审核的草稿。
- 引用、段落、JSON 协议和结构恢复使用冻结证据及有界只读请求；不能扩大执行权限、虚构测量值或通过撤回核心答案冒充完成。空白／截断 JSON 与错误结构采用不同处理，并保留真实用量和失败审计。
- 文件验证的暂时传输故障仅重试同一只读验证，不重新生成文件、不降低内容校验标准。
- 私有执行账本、同一步骤及源码摘要匹配时，程序源码才可作为 `method_only` 方法证据；注释和代码常量不能作为测量结果。
- 保留原始证据快照、已交付文件版本及私有失败收据；局部补交不得改写此前已发布成果。

## 4. 连续追问、状态与界面

- 按 plan 身份选择已审核历史，并精确匹配数据集／上传范围；新追问失败不遮住前轮成功，同一 plan 的撤销仍生效。历史事实可解释，但不能证明本轮进行了新计算。
- 空的本轮文件清单不再被错误表述为没有可交付文件；公开附件提示只使用当前实际发布的附件，不能借历史附件或正文文件名作证明。
- 计划标题、图标、步骤行和成功数共用结构化状态规则，区分全部完成、部分完成、失败、停止及执行中；普通页与分享／回放一致。
- SSE 增加执行状态投影，工具结束不等于执行成功；重复状态更新不显示为多次执行，同文件修订可折叠查看。
- 改善共用消息布局、成果展示及滚动区域焦点样式，保留键盘导航和内部控件焦点提示。
- 完善数据产品列表、下载、公开文件路径脱敏和失效附件处理；公开事件不承载私有审核目标、执行证明或宿主路径。

## 5. 兼容性与已知边界

保留 PlanActFlow、现有 Agent 工具循环、Cordis、FastAPI、SSE 及 Docker 隔离架构；不迁移或重跑用户旧任务，不恢复任务累计调用／Token／时长额度，不新增部署栈或公网端口。

确定性检查约束来源、身份、状态与发布边界，科学语义仍依赖模型审核，不能声称形式化证明所有结论。随附历史文档保留真实多轮验收失败记录；截至其最后记录，方法说明审核仍出现过拒绝。本次自动测试通过不等于真实模型连续追问已获得新的完整通过证明，也不抹去这些失败。
