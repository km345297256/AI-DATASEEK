## 修复

1. **分析被预览捷径截走。** 原路由只要整段请求任意位置包含“显示”“show”“view”等就触发预览，甚至文件名中的单词也能命中。改为仅接受整句都是指定原始文件预览的简单请求；复合分析、图例/标签要求、否定句和结构化成果要求进入正常分析。未知措辞保留完整问题交给执行器。
2. **真实证据因 JSON 编码被误拒绝。** 原始工具响应是 JSON，模型常引用实际字符串中的换行、引号、制表符。现在允许对合法 JSON 字符串值精确匹配；数值改写、空白改写、跨字段拼接、截断内容仍拒绝。诊断仅增加固定原因码和未核验要求索引。
3. **内部脚本冒充用户成果。** 多个收集入口原来自动上传输出目录中的 Python 等代码文件。现在依据本轮代码成果合同过滤；用户明确要求代码时仍按格式及文件身份交付。
4. **局部失败抹掉已完成成果。** 保留已验证上传及原验证收据；后续验证不可用、工作副本删除、修复时上传失败后仍显示部分完成，缺项只列未交付结果，不把整个任务误标为无成果失败。
5. **补传成功仍无法完成。** 上传失败的续传原来清空草稿后也丢失原工具证据。现在在私有 checkpoint 中保存有界原始观测，整体由现有 HMAC 封存，并绑定 owner、session、原步骤、输入和成果 SHA。通过现有配置、时序和指纹检查后，仅在补传分支恢复。两次连续上传失败后成功也只分析一次。旧 checkpoint 没有证据时不会伪装完整成功。
6. **短暂模型超时直接拒绝任务。** 真实新建上传任务在 8.33 秒后因前置决策超时被拒绝。工具禁用的前置决策调用现在使用现有有限传输重试和退避；不重试安全拒绝、坏 JSON、安全结构错误、401/400 或额度错误，不改变模型或凭据配置。
7. **时钟跳变误杀仍活跃的任务。** 真实 Iris 执行的墙钟间隔为 72.630 秒，但 provider 单调计时仅 11.974 秒；缺列审核分别为 87.597 秒和 1.256 秒。旧维护路径使仍活跃的本地执行因 30 秒租约失效而中断。现在只有同运行进程、原 task/attempt、权限仍有效的原协程可以经 Mongo revision/state/runtime CAS 续期，不重跑任务。取消、接管、回收或进程丢失后仍拒绝；竞争续租失败后的新记录也重新检查 task/attempt 身份。
8. **部分失败的真实原因被通用模板抹掉。** 实际缺列任务已算出 count=6、mean=7、min=2、max=12，并打印缺少 `missing_measurement`，但最终仅显示通用“待完成数据表”。现在局部修复终止后也进行只读证据审核，保留通过核验的统计和失败说明；缺失文件名来自合同及阻塞收据，原 partial/failed 状态和缺项保持不变。
9. **实际执行版本与保存代码的证据关联不清。** 第二轮 Iris 两个文件都正确，但图表目标被审核判为 unclear。现在将成功 `program_run` 收据中的 SHA-256 与同一步骤实际保存的源代码精确关联（含写入时增加的换行），让审核能核对已执行版本的方法。源码仍属于写入请求，不冒充测量结果；版本、路径、步骤不符以及失败/未结束执行均不关联。
10. **单个段落选错引用导致全部说明丢失。** 第二轮合成任务先执行的复合检查因缺少 `file` 命令退出 127，但后续统计与独立检查均成功。只有存在其他成功非写入工具观测时，允许一次只读引用更正；仍锁定段落类型并拒绝失败结果、伪造证据，不能启动计算或改写文件。
11. **合法相对文件身份被拒绝。** 对已观察 canonical 输入和已核验输出建立严格唯一的命名空间别名。真实存在的 `inputs/id/file.csv` 等表示不再误判；未知父目录、歧义、路径穿越、扩展路径和 MIME 伪路径继续拒绝。第二轮缺列任务的诊断为 relative_path，但原审核正文未保存，不能断言该别名问题是那次故障的唯一原因。
12. **局部修复改坏文件后丢失原有效说明。** 修复前保留有界、去草稿的原始观测快照。改写或删除已保护成果后，继续保留原附件和 execution_failed/partial 状态，只依据改写前的证据核验说明；后来的错误统计不能污染原先交付。
13. **只读追问绕过分析事实核验。** 当轻量路由明确依赖会话，且近期有主机发布的分析 outcome 时，清除轻量模型的未核验答案，交由既有分析流程完成本轮事实核验，保留本轮无需文件的合同。普通问候继续轻量回答；上下文仅增加历史成功/部分/失败状态，避免误将未核验历史当作已确认事实。
14. **条件分析漏掉指定交付身份。** 前置合同提示明确要求保留用户指定的每个输出文件名及分析目标；即使输入列不存在，该目标仍保留为待完成项，不能因为无法计算就删掉需求或编造数据。增加缺列条件下双输出的合同示例。
