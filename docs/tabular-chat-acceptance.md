# 表格技能对话样例验收

只使用仓库中的 4 行合成 CSV，验证“上传 → 选择固定技能 → 对话执行 → 报告文件 → Run 记录”。这不是生物研究场景，也不替代平台输入兼容性检查。

## 显式运行

从仓库根目录执行：

```bash
cd backend
uv run --frozen python -m scripts.check_tabular_skill_chat --execute --output ../.local/tabular-chat-receipt.json
```

需先启动本地 7000 服务，确保模型凭据有效。输出目录须存在，输出文件不得已经存在。脚本会调用已配置模型、创建并保留一个名为“技能闭环样例：CSV基础质检”的测试会话。若样例技能未添加，会临时添加并在结束时恢复；不修改自动启用偏好或模型配置，不触碰原有会话。测试会话和合成上传文件保留便于核查。

运行预算为 240 秒，单次网络等待上限 20 秒；超时或异常会请求停止尚未结束的测试会话。结束消息流后若 Run 仍运行或等待，也会请求停止。停止或安装恢复失败会单独记录，不能据此假称清理成功。请勿在验收期间并发修改该技能安装状态。

退出 0 只表示以下样例检查全部满足：消息流结束、前置决策没有拒绝、唯一 Run 明确成功且历史完整、技能精确版本和摘要一致、观察到脚本读取及 shell 调用、实际下载的报告含正确输入摘要和独立预期统计结果。工具调用事件本身不证明脚本逐字一致执行；本轮判据仍依赖服务端 Run 记录和报告，不是不可伪造的执行证明。

`blocked` / `incomplete` 均退出 1。凭据只保存阶段结果、标识和摘要，不保存模型回复、工具参数或配置密钥。格式校验与本次样例均不会自动提升目录的“尚未验证”状态。
