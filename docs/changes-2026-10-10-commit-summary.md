# 2026-10-10 改动说明

## 主要改动

### 模型路由与凭据隔离

- 新增统一模型路由解析与分层配置合并，切换提供商或 API 地址时不再隐式沿用上一条路由的密钥及请求头。
- 地址身份包含协议、主机、端口和路径，避免同一主机下不同租户或 API 路径串用凭据。
- 显式空密钥仅允许本机回环地址，用于无认证本地模型；不会回退继承默认密钥。
- 模型配置、规划器、执行器及视觉模型同步接入，补充凭据边界回归测试。

### 每次实际模型请求刷新运行事实

- 将动态运行事实与已接受的工具、技能和数据集上下文分离。
- 在实际模型调用准入时刷新运行事实，包括解析修复请求，避免重试过程中沿用过时状态。
- 保持原始消息历史和已接受上下文的语义，不以刷新运行事实重写历史。

### MCP 管理权限与并发安全

- 区分可见／可安装权限与配置管理权限；只有所有者或管理员可修改、删除配置。
- 对非授权查看者隐藏连接命令、参数、地址、请求头和环境变量，避免连接信息携带的凭据泄露。
- 更新时保留已有所有权及未显式修改的范围、风险级别；前端仅向所有者显示普通配置编辑入口。
- 数据库修改采用状态比较后写入，防止授权后状态被并发修改或覆盖其他服务配置；冲突返回 409，要求重新加载后操作。
- 管理员入口、审批流程及对应测试同步调整。

### 任务退出与资源清理

- 增加取消后等待清理完成的公共机制，避免重复取消打断资源收尾。
- 资源清理步骤即使部分失败也继续执行，最终汇总错误；同一销毁任务不重复运行。
- 调整 Redis 任务、Agent、输入投递和审批服务的生命周期处理，明确工作线程取消归属，补充关闭及结算测试。

### 对话阅读位置

- 优化折叠／展开分析步骤时的滚动锚点与临时留白，减少内容高度变化导致的阅读位置跳动。
- 普通会话、数据集探查页和会话切换同步更新，并增加浏览器实际布局回归。

### 持久化双向兼容审查

- 新增兼容记录必须分别说明“新读者读取旧记录”和“旧读者读取新记录”的行为与验证依据。
- 增加基于两个可信本地 Git 提交源码的独立审查入口，不切换工作区、不以登记快照代替源码，也不读取部署环境密钥。
- 审查成功只表示比较完成，不等同于语义兼容认证；源码提取会执行所选提交的 Python 代码，仅适用于可信提交。
- 更新持久化贡献说明及回归测试，不重写既有历史记录。

## 边界与注意事项

- 保留 PlanActFlow、SSE、FastAPI 及 Docker 数据隔离，不引入新部署栈或端口。
- 保留数据集只读挂载、宿主机路径允许列表及真实路径隐私边界。
- 更换模型提供商或端点后，可能需要显式补齐该路由的凭据；这属于防止凭据误用的预期行为。
- 自动化隔离测试不替代真实模型、生产数据库和科学分析准确性验收。
