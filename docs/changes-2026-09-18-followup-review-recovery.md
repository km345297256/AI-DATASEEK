# 连续追问与分段审核恢复（2026-09-18）

## 问题与边界

生产记录确认：前轮图表及数据表已经交付并通过审核；随后“把刚才的结果解释得更详细一点”的执行与审核模型调用均成功，没有超时或任务额度限制。审核回包的一个 limitation 段落未引用工具执行结果，触发 `unsupported_limitation`。该异常跳过原有引用纠正并替换整篇回答；空的本轮交付清单又被描述为“目前没有可确认交付的文件”，错误混淆了本轮文字解释与历史文件交付。

本次按通用证据与发布流程修复，不匹配数据集名称、文件名或某一句追问。不能通过隐藏真实失败、重复运行状态不明的操作、删除用户需求或把未核验的结论当作成功来解决。

## 通用修改

1. **段落隔离恢复**：错误引用、证据类型、文件引用和过长段落均进入只读纠正。已通过段落锁定，纠正只接收原问题及冻结证据。失败时保留可核验文字，不被单个异常全部替换。
2. **回答覆盖**：所有段落纠正都需要明确确认剩余回答覆盖原问题；撤回附加幻觉可以，但撤回核心答案、缺少覆盖确认或仅剩目录说明不能冒充分析完成。真实交付要求继续独立核验。
3. **历史限定说明**：唯一允许跨类型的纠正是历史 limitation 转 analysis。候选必须逐字等于所引、未截断历史来源中的完整段落；宿主添加历史归因并重新绑定真实引文。一般详细解释仍按 analysis 核验。历史证据不能证明新计算、新交付或当前文件可用性。
4. **禁止纠正扩大执行权限**：原 met/unclear 要求在引用恢复中不能变为 confirmed_not_performed，避免纯审核错误触发分析重跑。审核取消仍传播，不发布虚假完成。
5. **连续追问历史**：私有执行历史投影按 plan 身份索引已审核结果，不因失败的新追问遮住前轮成功，也不因复用 step ID 相互覆盖。同一 plan 的撤销仍生效；数据集及上传文件作用域必须精确相同，空集不是通配。执行模型和审核使用同一历史选择。旧投影只重建缓存，不修改历史任务事件。
6. **准确展示**：空本轮文件清单不再生成“没有可交付文件”的断言。前端只在当前最终 assistant 消息确有已发布附件时提及文件可用，不借历史附件、输入附件或正文文件名作证明。真正 partial/failed 状态仍保留。
7. **JSON 模式接口协议**：真实合成验收发现纠正调用缺少明确的 JSON 输出指令。初次审核有该指令，纠正审核却会依赖数据是否碰巧含 `json`，与 DeepSeek 的 [JSON 模式要求](https://api-docs.deepseek.com/guides/json_mode/) 不符。纠正提示词补齐 JSON 指令及 schema；新增真实审核入口与驱动的离线协议测试，安全诊断记录 HTTP 状态类别而不记录服务商错误正文。
8. **审核空回包恢复**：服务商 HTTP 200 的空白或截断 JSON 也进入原有有界传输重试，重发完全相同的冻结只读请求。有效 JSON 的错误 schema、工具调用、重复键和非有限数字不按瞬时错误重试；取消照常传播，不调用执行模型的 JSON 修复或重跑工具。
9. **脚本前置条件契约一致**：执行器允许沙箱中规范绝对路径的 Python 脚本，但旧前置条件探测仅接受最终成果目录，导致 scripts 等工作目录中的脚本从“缺失”变为“已写入”后仍被当作无进展。两端只读探测现与执行器路径范围对齐，仍检查真实字节、目录就绪、符号链接、竞争、大小及截止时间。恢复仍须私有执行回执确认 `not_started` 且前置条件确实改变；相同内容、pending/unknown 或较新的不确定尝试均不放行。未放宽数据挂载、宿主路径或最终交付边界。
10. **结构协议恢复**：独立审核 JSON 结构无效时，在接受任何段落前允许一次基于同一冻结数据的重新审核，不传入坏回包，也不调用执行工具。恢复回应额外确认回答覆盖；无法覆盖或仅剩目录说明仍不得成功。负面的 `confirmed_not_performed` 在此路径降为 `unclear`，协议错误不能授权新计算。工具调用、重复键、非有限数字与非对象回应保持拒绝；已有合规段落后的引用纠正仍严格限定原失败项。
11. **语法失败审计**：真实模型驱动在原 owner/scope 内校验 JSON；空白/截断回包记录 `failed / invalid_json`，保留真实用量及后续重试标记，不再被误记为成功调用。错误结构不伪装为传输失败，公共元数据不承载私有证明或回包正文。
12. **方法证据表示**：仅当私有启动回执、同一步骤及源码 SHA 全部相符时，在成功程序结果的私有元数据中附上完整 `method_only` 源码。原结果文本完全不变；代码常量、注释和元数据不可作为测量值的引用，validate-only 或未观测分支也不能证明分析执行。单来源或总证据预算不足就不附源码，不截断实际输出。纠正请求列出符合既有类型/状态要求的锚点，但不会自动补引用；保存成功仍不等于执行成功。
