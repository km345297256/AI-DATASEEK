# 2026-09-10 改动说明：Plotly 预览布局与列选择优化

## 范围

- 提交分支：`v2`。
- 对比基线：`347333f1aafc2dad99dc8a1c95c7910f3e58db57`。
- 本批包含 1 个前端组件、3 个测试／夹具文件，以及本说明；不修改后端、沙箱、依赖版本、部署配置或 Cordis 插件契约。
- 本次提交工作不部署、不重启服务、不访问用户数据，也不调用真实模型。

## 主要改动

### 预览控件适应文件面板宽度

- 横轴、图式和绘制按钮改为网格布局；根据组件容器宽度而非整个窗口判断布局，在 520px 以下将横轴单独排列。
- 控件保留自然高度，短面板通过滚动容纳内容，避免标签、选择器和图表互相挤压。
- 数组变量、视图及各维切片索引使用自适应网格；长变量名不再撑宽面板。
- 图表保留至少 360px 高度和可用绘图区域，统一边框、间距、聚焦与禁用反馈。

### 数值列改为明确的勾选列表

- 纵轴由原生多选框改为复选框列表，展示已选数量；数值列较多时列表独立纵向滚动。
- 最多选择 8 列，选满后禁用未选项，已选项仍可取消。绘图原有的最多 8 条序列限制保留，不是增加数据处理上限。
- 长列名在列表内省略显示，悬停标题提供预览中的列名；无数值列或没有勾选时给出提示。
- 初次载入仍默认选择首个可绘制数值列；用户点击“绘制”后更新图表。

### 长图例不再挤占主要绘图区

- 表格图例改到图表下方横向排列，设置 88px 高度上限及滚动；调整边距和横轴标题间距。
- 超过 18 个字符的图例显示“列序号 + 列名前缀 + 省略号”，避免相似长前缀无法区分。
- trace metadata 保留预览列名，悬停同时显示该列名与 x/y 数值。这里的列名仍遵循原 `plainLabel` 安全处理和 160 字符上限，不代表保留任意长度的原始字段名。

## 兼容性与边界

- 曲线、散点、直方图及数组曲线／热图继续使用现有读取入口与数据解析逻辑。
- 空值保持缺失，布尔值仍按 `false=0 / true=1` 转换；曲线不跨缺失点连线，不执行表格公式。
- `.npy`、`.npz`、`.mat` 的变量与切片交互保留，未扩大数组、表格或文件读取预算。
- 既有请求取消、过期响应检查、`ResizeObserver` 释放和 Plotly 清理逻辑没有被替换。
- AgentLoop、PlanActFlow、SSE、数据集路径校验和只读挂载边界均不变。
- 收益主要是窄面板可用性、列选择清晰度和图例占用改善；没有做真实大文件性能基准，不宣称后端分析提速或给出提速百分比。

| 场景 | 主要断言 |

| 360×500、600×700、1000×500 面板 | 控件不重叠、无横向溢出、24 个长列名独立滚动、图表保留可用区域 |
