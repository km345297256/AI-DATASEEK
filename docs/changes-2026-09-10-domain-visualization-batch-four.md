在[可视化插件管理](http://localhost:7001/plugins?tab=renderers)中独立启停，再从文件预览中选择视图。保持原有插件 ID、偏好及默认优先级。

| 插件 | 首版内容 | 主要边界 |

## 架构与效率

- 公有契约仍为版本 2，同一 API，保留 AgentLoop、PlanActFlow、SSE、FastAPI 与只读数据隔离。
- 增加有明确读器白名单的 `geometry` 结果类型；空间点、LAS、轨迹和网格各有专用负载验证，未放宽旧曲线与数组的预算。
- 五个插件仅 `file:read / preview / shared:false`，不给原始字节、作业、路径、任意 URL 或凭据能力。
- 树目录先行、用户明确选择、客户端显式版本绑定；返回值还需匹配初始目录、源大小及所选范围。
- DICOM / H5AD / LAS 的源可到 8 GiB，每请求累计取回 ≤8 MiB／128 次范围读取，单范围 ≤1 MiB。具体解码预算仍按格式额外限制，不等于 8 GiB 可一次可视化。
- DICOM ROI ≤128×128；空间点窗口 ≤8192；LAS ≤16384 点。GRO 与 VTU 是 ≤16 MiB 整文件预览，不冒充大型文件分块读取。
- 显示复用本地 Canvas、Plotly、Three.js；窗宽窗位、图形旋转缩放不再次取数，不新增模型调用、分析作业或生产依赖。
- 每类响应 ≤2 MiB。关闭或改变选择释放 WebGL、画布、图形与监听器，防止旧异步结果覆盖新选择。

## 隐私与科学语义

DICOM 不返回患者标识、UID 或任意标签。源 `PatientIdentityRemoved=YES` 与 `BurnedInAnnotation=NO` 加用户确认仅是准入条件，不保证像素确已匿名；功能限脱敏研究数据，不能用于诊断。AnnData 不读取 obs/var 的身份标签或未选表达数据，不把 X 宣称为未处理原始计数。

LAS 坐标保留 raw int32 与 scale/offset，先相对原点再转 Float32，避免大偏移下点云塌缩；不猜 CRS。GRO 保留 nm/nm·ps⁻¹；VTU 保留字段与节点／单元关联，单元标量仅在顶点算术均值处标示，所有单位或误差均不擅自推断。

### 独立科学参照与边界测试

临时环境固定使用 pydicom 3.0.1、AnnData 0.11.4、laspy 2.6.1、MDAnalysis 2.9.0、meshio 5.3.5，不新增生产依赖。DICOM 包含 24 组官方像素解码、8 组灰阶显示值对照；空间组学覆盖真实 AnnData writer 的 dense/CSR/CSC 与压缩组合；LAS 与 GRO/VTU 验证独立读取／写出往返，非互相调用本项目解析器冒充参照。

测试发现 MDAnalysis 发布源码的默认隔离构建可能缺少完整 Python 包，固定构建链后又遇到部分预生成 Cython 文件与 NumPy 头不匹配。最终只在临时参考环境中使用官方 `CYTHON_FORCE_REGEN=1`、setuptools 75.8.0、wheel 0.45.1、Cython 3.0.12 与 `--no-build-isolation`，明确重新生成全部 13 模块。生产 NumPy 保持 1.26.4。测试阶段同时保留镜像原有 GDAL 的 Python 路径，避免测试命令覆盖路径造成假性缺依赖；最终完整回归无跳过，不将中间失败计为通过。

共享边界额外有 92 项后端、49 项真实窗口协议测试：新几何类型不授予旧读取器，五插件均校验 owner、私有产物、启停、客户端版本、选项与能力；包含 8192 个原子及其速度的合法 GRO 负载能通过公有预算，旧数组仍为 16384，旧通用复杂度仍为 100000。VTU 在解析节点开始事件即时实施 XML 结构预算，避免先完整建树再拒绝。
