# 工具收尾、配置竞态与回归门禁更新

日期：2026-09-29；分支：`v2`；对比基线：`1eb08c52d88ade3a8afb78f29e382350a3f8fca1`。

## 1. 工具批次中断收尾

- 新增工具结果收尾模块，逐调用保存安全的 ToolMessage，再发布完成事件，避免同批后续中断丢失已完成结果。
- 区分尚未调用与执行结果未知，沿用现有账本及所有者检查；CALLING 展示事件不等于执行证据，不自动重放工具。
- 在 WAIT／DONE／ERROR 发布前完成有界收尾，覆盖取消、消费端关闭、失租和保存失败；新用户回答作为新输入，兼容旧的未闭合提问调用。
- 持久化服务不可用时保留原异常及进程内观察，不能承诺一定落盘，也不把此次改动称为跨库原子事务。

## 2. Agent 配置目录竞态

- 抽取共享配置目录，采用请求／选择世代，同世代查询复用，保存后强制刷新。
- 迟到响应不能覆盖新选择；查询失败保留最近成功状态，新的成功查询仍可确认配置确已删除。
- 回归核验最终分析请求实际携带用户选中的配置 ID，而不只检查选择器显示。

## 3. 持久化子协议与缓存观测

- 在既有六个持久化根之外，独立登记 MCPImageRef、SpillArtifactRef、SpillArtifactNotice、SpillArtifactRecord、AnswerReviewMarker、ModelTraceRecord 和 TokenUsageRecord。
- 记录实际持久化入口及版本，追加快照，不覆盖旧基线。AnswerReviewMarker 与生产读写绑定；旧 MCP 引用 key、占位文本及旧记录回读纳入测试。
- 可选记录缓存读取／写入 Token，以及实际请求工具 Schema 的摘要和数量。不保存原始工具 Schema 或 metadata，不扩展公开 trace 和 UI。
- 缺失、冲突或非法缓存计数保持未知；DeepSeek 未命中量不冒充缓存写入量，不与原 prompt／completion／total 重复相加，不改变计费或配额语义。

## 4. 浏览器门禁

- 新增 `npm run test:browser`，统一回归脚本在前端构建后执行四组 Chromium、两组 WebKit 场景；缺运行时明确失败，不静默跳过。
- 覆盖布局／输入、追问结果、任务状态、固定请求 ID 恢复、接收确认后只读回放、迟到响应、历史前插及图片加载后的阅读锚点。
- 使用真实组件／控制器和合成拦截请求，不访问业务部署或用户数据；局部布局中的既有组件替身仍保留，不代表整站或操作系统输入法验收。

## 5. 兼容性边界

保留既有 PlanActFlow／Agent 执行架构、Cordis、FastAPI、SSE、数据集只读挂载及路径 allowlist。不切换模型或接口，不增加任务累计配额、权限或产品域，不改 `.env`、Compose、端口、生产 UI 模板和 CSS。

结构门禁不等于科学结论正确，工具收尾不是重新执行。本次只提交并推送代码，不部署、不启动 Docker、不调用真实模型或重跑分析任务。
