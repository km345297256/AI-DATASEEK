## 主要改动

### 1. 生产发布与迁移保护

- 默认前端端口改为 `8888`，公开访问地址统一为 `https://dataseek.4fair.cn/`，同步 Compose、配置示例和项目文档。
- 增加 `run.sh production` 受控入口：默认只读预检，显式参数才更新服务；支持前端单独更新、固定七镜像的迁移后整栈启动及受控停服。
- 发布从 `/data2/current` 进入，校验版本目录、镜像清单、发布锁、端点、服务身份及持久卷；停用旧 `/root` 发布入口，防止绕过保护直接更新容器。
- 持久状态约束在 `/data2/state/` 或 Snap hostfs 对应视图，Compose 增加可配置固定容器名、外部卷、Redis 和 MongoDB 配置持久化、Jupyter 工作区父卷。
- 受控停服先归档动态沙箱，再停止相关服务；保留固定服务容器及卷。新增离线部署和归档测试。
- 这些代码不表示本次已经执行迁移、发布、停服或修改生产数据。

### 2. 沙箱所有权及应用关闭

- 加强沙箱分配、预热、池关闭和应用退出的所有权及清理逻辑，避免取消、启动失败或关闭过程留下资源或重复销毁。
- 调整 Agent 生命周期和应用关闭顺序，补充引导、分配和关闭回归测试。
- 统一短期数据读取／可视化辅助容器的安全选项；仅在明确配置时增加 AppArmor 堆叠，仍保留 `no-new-privileges`。

### 3. Jupyter 工作区持久化

- 支持指定宿主机工作区根目录及后端存储根目录，并校验会话身份、挂载参数及实际卷配置。
- 使用禁止符号链接跟随的目录访问和独立所有权记录，防止错误复用其他会话目录。
- 工作区与笔记本容器生命周期分离，过期笔记本的工作目录可保留为归档；补充存储边界测试。

### 4. 停止分析与 SSE 状态恢复

- 区分“停止请求已确认”和“终态事件已收到”，停止后继续观察对应输入的终态，避免过早清除界面状态。
- 更新会话接口、历史读取和输入状态恢复，保留输入身份及会话切换隔离，防止误重发已接受请求。
- 同步数据集探查页面及浏览器恢复测试，继续使用现有 SSE 通信结构。

### 5. 前端版本提示与终端展示

- 构建生成基于实际产物的 `release.json` 和页面版本标记，不暴露 Git 元数据、环境值或宿主机路径。
- 增加后端客户端协议声明及前端兼容性提示；只提示更新、协议不兼容或资源异常，不自动刷新、重发请求或取消分析。
- 调整相关静态资源缓存规则。
- Shell 展示仅根据明确的进程返回码显示退出信息，工具调用成功不再被当作进程退出码；新增 Chromium / WebKit 终端场景。

### 6. 模型响应与领域预设

- 新增模型响应投影和验证：只提取明确答案文本，不将推理、工具参数或未知多模态块直接字符串化为答案。
- 区分普通空完成、异常结束和拒绝；保留工具调用及非文本响应的语义，结合已有有限重试与调用记账。
- 新增数学领域预设，版本提升为 2；强调题目内容是数据、标注不等于验证结论、数值检查不等于证明，并不内置证明助手。
- 插件目录关闭处理及对应回归同步完善。
