# 数据获取样例验证

NCBI 仅用于验证一个公开来源的小数据包。产品仍面向通用数据检索、导入、转换与分析及分类 Skills 仓库，不扩展生物研究功能。

## 复现

在仓库根目录执行：

```bash
cd backend
uv run --frozen python -m scripts.validate_data_acquisition_sample
uv run --frozen pytest tests/test_acquisition_sample.py
```

脚本固定官方 HTTPS 来源与版本 GCF_000009045.1，不跟随重定向，不读取环境代理；下载上限 10 MiB，ZIP 展开预算 16 MiB、最多 64 个条目。包在内存读取，不向磁盘解压、不写入会话数据库。输出 JSON 凭据至标准输出；失败退出码为 1，不返回成功凭据。

验证 ZIP CRC、清单与报告的精确版本、必要文件存在以及官方清单 MD5，并记录包和每个文件的 SHA-256、字节数、来源 URL 与获取时间。MD5 用于与来源清单比对，不作为独立来源认证。README 等没有来源 MD5 的文件明确标记未通过来源校验，不冒充已核验。

## 能力边界

此结果只证明独立脚本完成一次获取与校验。没有执行生物分析，没有登记生产数据版本，没有接入聊天下载按钮，也没有交付持久下载、恢复调度或完整分析闭环。现有获取计划仍显示未启动，不能用本验证将产品状态改成已下载。

下一步转向通用 Skills 分类、选择与组合，以及通用数据导入和获取；NCBI 专用分析不再作为升级前置条件。

来源契约参见 [NCBI 官方数据包下载说明](https://www.ncbi.nlm.nih.gov/datasets/docs/v2/how-tos/genomes/download-genome/)。
