# 2026-09-30 改动说明

## 范围

- 分支：`v2`；本批代码基于 `40157c8`，同时推送此前尚未上传的提交。
- 本次只整理、验证并提交现有改动，不部署或重启生产服务。
- 保留 PlanActFlow、FastAPI、SSE 与 Docker 隔离边界。

## 主要改动

### 1. 长任务执行与主动取消

- 移除分析阶段、模型请求、工具执行、校验及相关持久化操作的固定耗时截止逻辑，避免正常长任务被提前终止。
- 活跃分析沙箱不再按固定存活时间过期；容量等待持续轮询，仍保留并发容量限制，而非无限创建容器。
- 文件校验支持取消与断连信号，等待工作线程清理；取消校验不会被误认为文件损坏并触发重新生成。
- 更新配置示例及超时、取消、沙箱生命周期相关回归测试。文件大小、数量、结构和权限限制不等同于耗时限制，仍须遵守。

### 2. 用户评估结果与历史上下文

- 调整结果发布路径，不再依赖隐式模型自审批准才能交付；用户明确要求审核时仍可开展相应分析。
- 新增严格的 `ResultAssessmentMarker`，标记 `user_evaluated` 和 `scientific_review=not_performed`，并绑定数据集及输入文件范围。
- 先前已交付结果可以用于同一授权范围的追问，但不能伪装成独立验证的科学结论，也不能替代当前执行或文件交付凭据。
- 执行历史缓存版本由 2 升至 3，旧缓存从原始事件重建，不修改或重跑历史任务。
- 前端结果提示、图片展示及对应测试同步更新。

### 3. 程序准备状态

- 增加可选 `dispatch_status` 展示信息，区分程序尚未开始与实际执行失败。
- 更新任务计划、工具时间线及准备状态的展示，提示先补齐脚本或目录，而非通过切换执行器掩盖准备失败。
- 新字段不赋予重放或执行成功权限；旧事件缺省值保持兼容。

### 4. SVG 安全预览

- 新增 SVG 插件、前端文件预览组件、后端预览载荷验证及沙箱渲染服务，补充示例和恶意输入测试。
- SVG 原件仅用于附件下载，预览采用隔离渲染后的 PNG，不在浏览器内直接执行 SVG 内容。
- 后端验证 PNG 结构、尺寸、校验和与解压像素范围；前端验证预览载荷，限制异常内容。
- 同步生成可视化适配器及插件测试目录，合约检查覆盖 78 个适配器。

### 5. 持久化与兼容性

- 模型追踪写入不再使用短时限截断，保留取消与真实存储错误的处理。
- 更新事件记录、执行历史、模型运行时及持久化合约清单。
- 新增两份持久化快照，记录结果评估标记和程序准备状态的兼容策略。

## 运维注意事项

- 取消固定时限不保证任务一定完成；外部模型、存储或原生库长期无响应时，需观察进度并主动取消，资源可能占用更久。
- “执行和交付完成”不代表科学正确性已获认证；重要结论应由用户核对方法、数据与输出。
- 保留数据集只读挂载与宿主机路径允许列表，不向浏览器公开真实宿主机路径。
- 未纳入原始数据、`output/`、新增 `outputs/` 内容、本地重复备份、真实密钥、运行日志和测试缓存。
