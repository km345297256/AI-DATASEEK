## 一、从数据集文件列表直接打开预览

- 探查页文件树对有匹配且已启用插件的文件显示预览按钮，提供加载状态、不可用提示和重新连接入口。
- 点击后将数据集内的逻辑相对路径交给服务端校验，生成绑定用户及数据集的不透明 `dataset-preview:` 文件引用，复用现有文件面板和插件选择；不为预览复制一份上传文件，不创建 Agent 会话。
- 新增 `POST /datasets/{dataset_id}/files/preview`；返回公开 `FileInfo` 及关联文件信息，不返回实际存储路径。
- 当前支持本机已验证、只读的数据来源：托管数据集卷与 allowlist 内的宿主目录。未验证、非只读、远程节点或多义路径拒绝预览。
- Shapefile 仅关联同一逻辑目录及完整文件名主干的配套文件，最多 5 个，避免跨目录按 basename 误匹配。
- 文件读取前后重新校验用户访问权、数据集状态、来源及插件目录版本；文件变化、插件停用、会话切换或组件卸载后，迟到结果不能打开旧预览。
- 新增只读存储适配层：普通上传文件仍交给原存储处理；数据集预览引用不允许删除源文件或生成绕过鉴权的预签名链接。
- 预览引用单独存储并设置 7 天有效期，只保存服务端关联信息，不持久化源文件内容。

路径公开投影集中到 `dataset_file_paths.py`，列表与预览复用同一规则，兼容旧记录的内部目录前缀；歧义路径不静默选择第一项。

### 两类读取边界不能混淆

科学格式解析 worker 仍使用无宿主目录挂载的隔离容器。宿主数据集取字节使用另一种固定代码的短命只读 helper：只读绑定 Docker 宿主根到 `/host`，以 UID 0、丢弃全部 capabilities、无网络及禁止提权运行，再按当前 `DATASET_HOST_PATH_ALLOWLIST` 和已授权文件清单限制读取。

该 helper 不是非 root、无挂载的科学解析容器；其只读挂载范围大于单个数据集，安全性同时依赖服务端授权、白名单和固定读取代码。文件描述符逐级读取拒绝符号链接、设备和 FIFO，并限制字节量、时限与并发；真实宿主路径不会交给浏览器。

## 三、协议协商与受控执行

- 旧客户端不传版本时，`GET /visualizations` 仍只返回 14 个 v1 描述符；新客户端传 `contract_version=2` 获取 v1 与 v2，未知版本拒绝。
- Node、Python、TypeScript 三端校验固定的适配器、读取器、数据种类和视图组合；声明不接受任意脚本、URL、主机路径或命令。
- 新增结构化 `/files/{id}/visualization-v2` 与有界二进制 `/files/{id}/visualization-content` 入口，继续检查文件归属、插件启用状态、文件版本和目录 revision。
- 扩展原生读取器运行在无网络、非 root、只读根目录、无宿主数据挂载的短命容器；输入通过有界协议传递，不把第三方解析库引入 FastAPI 主进程。
- v2 原始输入最多 64 MiB，具体适配器可更小；派生 JSON/媒体输出最多 8 MiB，并有数组、表格、层级和图像独立限制。
- v2 容器限制为 1 GiB 内存、1 CPU、96 PID、512 MiB 临时空间、50 秒外层期限，另有 55 秒独立硬时限和自动删除；不放宽原 v1 预算。
- Docker create/start 之间的崩溃仍可能留下未运行的容器元数据，不宣称任意崩溃点都无残留。

## 四、显式 QC 作业

- FastQC/MultiQC 必须由用户主动启动，打开文件本身不自动运行质控。
- 新增文件作用域的作业创建、列表、状态、取消和结果接口，复用现有 AnalysisJob 与 Spill Artifact Store，不制造虚假的分析会话或改变 SSE。
- 结果为私有产物，按用户、文件作用域、内容摘要、文件版本及插件 revision 核对后读取。
- 离开 QC 视图会请求取消未完成任务；插件停用后仍允许用户取消自己拥有的任务。

## 五、构建与离线资源

- 前端构建镜像从 Node 18 升级到 Node 24，匹配新增锁定 SDK 的要求；构建堆限制为 4 GiB，生产仍由原 nginx 提供静态页面，没有新增 Node 服务或端口。
- Docker 安装前端依赖使用 `npm ci --ignore-scripts`；`package-lock.json` 随代码提交。H5Web/NMRium 所需 React 只用于适配器内部，不替换 Vue 主应用。
- SDK Worker、字体、WASM、PDF CMap 等固定资源本机分发；NMR 工作台独立预构建，工作区偏好只放内存，不恢复历史浏览器存储内容。
- 地图等拥有全局 Worker 的 SDK 使用独立本地 iframe 管理生命周期。Cesium 所需动态函数和 Blob 脚本许可只放在其独立预览环境，不放宽父页面或其他插件策略。
- nginx 明确为 `.mjs` 返回 JavaScript 类型；缺失可视化资源返回 404，不回退为 SPA 首页。
- 沙箱增加 FastQC/Java 以及锁定的 MetPy、MultiQC、olefile、RDKit、uproot 等依赖，Python 锁文件同步更新。

## 六、兼容性和已知限制

1. 原上传、下载、v1 文件预览、分析消息与工具目录保留；新增插件不进入 Agent 模型工具列表。
2. 不加载在线底图、天文目录、外部基因组或远程模型；不执行 Office 宏、公式计算、ROOT 绘图脚本或 NPY pickle。
3. 当前不覆盖任意大文件、多文件外链/伴随索引、DICOM 转换、原始 NMR 全流程、Office 编辑或幻灯片动画；医学影像只用于研究，不作诊断。
4. 数据预览及格式验证不保证科研方法、统计结论或每种上游文件语义都正确；具体限制见各适配器 README。
5. 仓库记录的非商业研究用途不免除上游许可要求；此次不新增许可授权，发布或再分发前仍需核对相应条款。
6. 容器更新仍使用现有 `./run.sh` 和唯一 Compose 栈。本次只提交代码与文档，不部署、不新增前端端口。
