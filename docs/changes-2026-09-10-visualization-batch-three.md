## 如何使用

1. 在数据集管理中登记包含数据的本地目录，进入探查页面，打开文件。
2. 在“可视化”选择器选择对应的“窗口/分块”插件。先读取结构，再指定变量、索引、层级或区域，点击读取按钮。
3. OME-Zarr 需登记**完整目录**，包括 `.zattrs`、`.zgroup`、各层 `.zarray` 和数据块。选择形如 `image.zarr/.zattrs` 的文件，不是单独上传 `.zattrs`。不支持公网对象存储、嵌套多图像、plate/well、labels、Zarr v3 或其他 NGFF 版本。
4. 支持的未压缩大型 CZI 使用新插件；原 `viz-czi` 保留已验证的 ≤64 MiB 整文件读取能力，包括其原有压缩类型。新插件不能读取的方言不会自动退回整文件下载。

## 不是只移动组件：协议与结构适配

- 唯一批准源 `contracts/visualization-adapters.json` 同步生成前端、后端和 Cordis Host 三份契约；新增组合需要四层明确批准，不接受任意脚本、任意读取器或远程 URL。
- 复用私有 `dataseek-window-v1` 范围协议，新增固定读取器预算配置；公开 SSE 和业务消息结构没有改变。
- `window` 输入上限计量的是一次请求**实际取回字节总量**，不是允许整文件加载。所有新范围源硬上限为 8 GiB；单次传输 ≤1 MiB。
- 首次只返回结构。之后的数据请求必须绑定首次结构返回的 `version`，并严格校验返回窗口与请求窗口一致；单位、dtype、数值范围、形状与预算统计经过独立前后端校验。
- 同语义文件/插件对象的目录轮询不重复请求；文件版本、插件版本、能力或开关改变才失效。保留此前自动刷新修复、显式刷新和 Shapefile 框选功能。
- 插件停用、切换文件、关闭预览时取消旧请求，销毁 Plotly、图像 URL、Canvas 等资源，晚到的结果不能重新显示。无新增 CDN、外网底图或模型调用。

## 读取效率与资源约束

| 读取器 | 每次累计取回上限 | 范围请求上限 | 其他主要约束 |
| --- | --- | --- | --- |
| HDF5/NetCDF4 | 8 MiB | 128 | 单块解码 ≤4 MiB，选中块几何解码量合计 ≤16 MiB；有界元数据/压缩块缓存 |
| OME-Zarr | 32 MiB | 256 | JSON 元信息每对象 ≤64 KiB；单块解码 ≤4 MiB、合计 ≤32 MiB；none/zlib/gzip/Blosc 固定白名单 |
| 大型 CZI | 32 MiB | 4,096 | DV 目录 ≤4 MiB、≤16,384 项；只读覆盖所选 ROI 的原始像素行 |
| EDF/SPE 仪器图像 | 32 MiB | 2,048 | 有界帧索引与所选 ROI；不读取其他帧的像素正文 |

新解析容器无网络、无端口、无主机/数据集挂载、非 root、只读根，限制为 1 GiB 内存、1 CPU、96 PID、512 MiB tmpfs。源数据由主机授权代理逐次读取，而不是向解析器提供路径。原生理 EDF/BDF 的 512 MiB /32 PID /16 MiB tmpfs 预算保持不变。

窗口请求 50 秒、单次源读取 10 秒，隔离容器有 55 秒硬截止。取消后并发槽保留到真正的底层读取与容器回收结束。OME 范围作用域另有 70 秒总截止与有界并发的资源快照检查；Docker 不可用时不退回主机解析。

实测合成数据：

- 实际 h5py 创建的 **1,200,002,048 字节稀疏 HDF5**：曲线只取回 **16,384 字节/1 次**，热图 **32,768 字节/2 次**。没有全文件哈希、上传或内存映射。
- Zeiss 官方 writer 生成的 **80,008,896 字节未压缩 CZI**：结构 **2,940 字节/3 次**，所选 ROI **3,292 字节/8 次**。
- 实际 Zarr MemoryStore 生成的两级 TCZYX 合成源 **6,600 字节**：结构 **3,519 字节/4 次**，层级 1 指定平面与 ROI **3,555 字节/5 次**，只展开 1 个 48 字节数据块，数值与原数据一致。

这些证明了指定预览的按需读取路径，不是对所有真实格式、所有磁盘布局或 Agent 分析总耗时的保证。高碎片文件、超大索引、超预算块会明确拒绝，不偷偷提高预算。

## 数据语义与安全边界

### HDF5 / NetCDF4

使用 [h5py 文件对象接口](https://docs.h5py.org/en/stable/high/file.html#python-file-like-objects)提供 seek/readinto，输入始终来自授权范围代理。禁止软/外部链接、VDS、外部原始存储、引用/变长/复合类型、未知或动态过滤器。标准压缩块先进行有界校验，再交 HDF5 解码；拒绝超量膨胀、尾随数据、错误校验和，缓存避免同一压缩源的重复传输。预检和 HDF5 各做一次有界处理，`decoded_chunk_bytes` 是选中块的几何字节量，不是两次 CPU 工作量相加。

本期显示**原始存储值与索引轴**。不会自动应用 CF `scale_factor`、`add_offset`、填充值掩膜或时间日历；相关属性仅作提示。有限填充值保留，非有限数转成明确空值；超出 JavaScript 安全整数范围的 int64/uint64 拒绝，不静默损失精度。地图叠加仍使用原地图插件。

### OME-Zarr

依据 [OME-NGFF 0.4](https://ngff.openmicroscopy.org/0.4/index.html)和 [Zarr v2](https://zarr-specs.readthedocs.io/en/latest/v2/v2.0.html)实现受限本地单图像读取；0.4 是本期支持版本，不声称是最新标准。

新增**精确的多对象数据集作用域**，仅授予同一已登记 `.zarr` 图像中的数值层与块键；不是通用目录浏览、任意文件或对象存储接口。浏览器只持有既有 opaque dataset-preview ID，不接触宿主路径或块 URL。为 `.zattrs` 增加精确文件名特例，未开放 `.env` 等任意隐藏文件匹配。

作用域由用户、数据集声明、验证过的只读位置与全部成员 stat 快照绑定。每次读取重新核对声明、位置和选中成员版本，完成时再检查全部成员；未读取的块变化也会使结果失效。归档、撤权、移动目录、链接替换、跨用户访问或缺失块均失败关闭。Host 路径继续验证 `DATASET_HOST_PATH_ALLOWLIST`，沿用现有只读辅助读取器；新增批量 stat 不跟随链接、不传回文件内容。

本期轴序限定为 `T/C/Z/Y/X` 的有序子序列，必须以 `Y/X` 结束；只接受 C-order 实数标量数组和规范的数值层/块键。只返回明确的轴类型、合法单位、层级 shape/chunks/dtype、scale/translation 与原始数值。不读取远程 URI，不执行动态 codec，不补零填充缺失块，不返回 OME 原始身份字段。画布灰度归一化只用于显示，悬停可看原值、索引与变换后的坐标；不会把显示值当作定量测量值。

### CZI 和仪器专有格式

大型 CZI 是针对已批准未压缩布局的独立有界读取器，使用官方 writer 合成文件核验；**不是把官方 filename API 伪装成随机读取**。不创建含伪零洞的临时 CZI，不获取任意附件/XML；压缩、金字塔、多场景、缺口/重叠和分卷都明确拒绝。

ESRF EDF 与生理 EDF/BDF 依魔数、头字段和显式插件严格区分。SPE 2.x 使用固定头中的布局信息，不解析未知专有附带内容、不推断波长/能量标定。灰度范围只影响屏幕显示，原始文件始终只读。方言、类型与参考格式说明详见[仪器图像支持边界](instrument-window-formats.md)。

没有新增运行时依赖，复用已锁定 h5py、NumPy、numcodecs、Zarr 与 pylibCZIrw；不引入完整仪器桌面软件。原第三方包许可继续保留；独立读取器不代表获得厂商私有格式的全面兼容认证。
