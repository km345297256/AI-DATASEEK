# 分析程序真实回执与调试循环控制

## 边界

本次修复针对通用自定义分析执行链，不包含任何数据集、文件名、字段名或科学分析方法特例。不恢复任务工具调用、令牌或累计耗时额度，不迁移或重跑历史任务。数据集只读挂载、宿主路径 allowlist、独立操作超时与进程树取消保持不变。

## 执行真值

- 新增 `program_run(id, exec_dir, script_path, argv?, timeout_seconds)` 和沙箱 `/api/v1/shell/program`。当前直接程序入口支持 Python `.py`，参数是字面字符串列表，不进入 Shell。公开参数使用 `argv`，避免工具 Schema 将 Python `args` 参数重命名为 `v__args` 后无法绑定；沙箱内部传输中的 `args` 由可信适配器显式映射。
- 沙箱读取普通源码文件到匿名快照，由固定解释器执行该版本。记录源码 SHA-256、实际退出码和结构化异常诊断；保留 `__main__`、同目录导入、dataclass/pickle 与 traceback 源码语义。程序打印的文字不能决定成功状态。
- 主机通过私有 operation ledger 绑定调用、沙箱、命令身份、程序版本及终态。不接受模型/普通工具自己声明的回执；生产 `NodeBoundSandbox` 包装和已知 worker adapter 均有严格识别。
- 源文件不可读等启动前错误为 `not_started`。执行未知时仍不自动重放；取消操作仍终止同一进程树。
- 已知保存 Python 脚本的 Shell 调用在执行前引导到 `program_run`，覆盖普通管道、常见包装和前置环境赋值。分类器不是任意 Shell 语法的安全解释器：动态表达式及 inline 诊断仍受原有沙箱授权管理，不能宣称所有语言/命令都获得 Python 独立回执。
- 输出采用 32,000 字符以内的头尾采集并明确标记中间省略，保留开头验证摘要与末尾异常；退出状态与显示日志独立。重要质量指标应写为紧凑证据或成果文件，不能把被裁剪内容当作已验证证据。源码大小、日志采集和独立操作等待边界不是任务总额度。

## 验证与无进展控制

- 执行规则先检查实际记录与结构，再用断言和紧凑质量指标验证不确定的自定义解析，验证通过后分析/绘图/导出。保留可复用解析器和 validation-only 入口；已有等价校验的确定性工具不做冗余检查。这是模型执行协议与宿主进展控制，并非对任意科学解析正确性的形式化证明。
- 统一记录完整写入、局部替换和追加的程序修订。只有对应程序的可信终态才解除它的未执行草稿状态；任意 Shell 成功、读取自产代码或改变源码哈希不能清零所有程序。
- 反复出现相同错误、没有新输入证据时切换诊断，不再盲目补丁重跑。不同实际错误、新原始数据证据、健康的其他程序可以继续。旧成功回执不能豁免后来启动失败或执行未知的调用。
- 明确的语法/名称类代码错误允许通过同一程序核心 `file_read` 的新内容观测开放一次纠正试验；此观测不算数据/成果进展，不解除其他程序的阻塞，同一内容不能反复使用。数据转换/字段错误不能靠自产脚本读取解除。
- Python 专用硬拦截仅适用于受支持的 `.py`。不把 R、JS、Shell 脚本强塞进 Python 执行器；这些语言保留原工具能力与通用重复失败保护。
- 删除独立编译、固定重跑整段代码的旧快捷分析分支。目录、元数据与 quicklook 的自定义 fallback 都进入同一个受控工具循环，保持目标文件、分析维度、交付合同；目标未核实不扩大范围。失败 quicklook 在该 fallback 中不可重复选择。

## 回答和界面

- 仅对无效引用项做一次无工具纠正，使用冻结来源的 `evidence_id`，由主机解析为原始片段后严格重验。已通过的段落锁定；纠正不可用时仍保留这些段落，不发布未核验内容，不产生分析重跑权限。
- 单个调用的状态更新不计为多次执行。步骤内同文件修订合并展示，可展开每次操作和时间，运行/核验保持单独显示；显示不改写事件历史。
- SSE 单独投射 `execution_status`，区分“事件已结束”和“工具确实成功/失败”。不通过状态文本猜测成功，不暴露私有诊断或宿主路径。

## 当日回归修正：公开参数与 Python 签名不一致

用户新任务的 `program_run` 在约 18 ms 内抛出 TypeError，实际 Python 程序没有启动。公开工具生成过程把保留名称 `args` 改为 `v__args`，模型据此传参；此前主要直接调用 `_arun` 的测试绕过了这层 Schema，不足以验证真实入口。通用异常分类随后将它记为执行未知，触发只保留代码、图表未完成和分析说明未核验的提示。

- 公开入口改用 `argv`，提示、回执身份匹配和模型可见 Schema 同步修改；内部 REST 参数仍由适配器显式映射为 `args`。不增加旧字段兼容。
- 核心工具在进入函数体前使用真实 Python 签名绑定参数。仅绑定失败明确分类为 `tool_signature_mismatch / not_started`；函数体内部的 TypeError 仍不能据此推断没有副作用，不自动重放。
- 回归覆盖公开 Schema → `ainvoke` → AnalysisJob 独立 worker → NodeBoundSandbox → HTTP 适配器 → 私有回执，含遗漏/null/空/非空参数、真实成功/失败和字面 Shell 字符。所有 ShellToolkit 声明增加 Schema/Pydantic/Python 签名一致性门槛。
- 后端全量 5,769 passed、30 skipped，190 subtests passed。前端和沙箱生产源码本次未变更。
- 新增可复用 `backend/scripts/smoke_program_execution.py`，使用最终后端镜像和独立空白 Linux 沙箱实际执行预检、绘图及故意失败：3 次调用取得 3 份确认回执，无 pending execution，生成 PNG 通过真实内容验证。该测试不调用模型、不写生产会话记录、不读取用户数据；验证后移除临时容器和合成文件。
