## 已修复问题

| 用户场景 | 修复前的问题 | 修复后的行为 |
| --- | --- | --- |
| 进入数据集后立即发送 | 详情已到、历史尚未恢复时可提交；迟到恢复可能覆盖新任务 | 初始化完成前锁定输入与提交入口 |
| 停止后立即发起新分析 | 迟到的停止请求可能终止新任务 | 等待停止确认再解锁，重复停止合并，旧响应与新会话隔离 |
| 批量或分片上传时切换会话 | 旧批次后续文件可能进入新会话；移除/失败后仍排队上传 | 检查附件所属数组和组件生命周期，过期、移除或失败后停止调度 |
| 下载较大数据产品 | 整文件读入内存、事件循环同步压缩、异常时临时文件泄漏 | 1 MiB 分块读取、后台压缩；失败/取消关闭临时文件；校验大小和版本 |
| 编辑/下载数据产品目录 | 绝对路径被静默归一化，重复文件或文件/目录冲突可保存 | 创建、编辑、下载共用相对路径校验；拒绝重复、冲突和多个主文件 |
| CSV 编码和字节采样 | UTF-16/32 乱码，多字节截断误判编码，引号内换行可能产生半条样本 | BOM 识别、增量解码、仅接纳完整记录；完整文件坏记录明确失败 |
| CSV 行列边界 | 重复表头后缀碰撞；宽表未标记截列；行预算之外坏记录破坏有效样本 | 列名去重防碰撞、明确截列标志、达到行预算即停止解析后续记录 |
| 经典 NetCDF | 所有文件强制使用 h5netcdf，CDF1/2/5 无法读取 | 根据文件签名选择已有 netCDF4 或 h5netcdf 引擎 |
| 极窄或极高栅格 | 单边最小值取 1 后采样像素乘积超预算 | 对最终采样尺寸再次施加像素乘积约束 |
| 大文本默认预览 | 先读取整个文件，再截取返回；远尾坏编码也导致短预览失败 | 无行范围时直接读取字符上限加 1，保留显式全文操作语义 |

已经发出的上传 HTTP 请求可能完成；上传修复保证结果不会进入新会话，并停止后续文件/分片调度，不声称撤回已发送的数据。
