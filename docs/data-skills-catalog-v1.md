# 分类技能目录 v1

入口：插件 → 技能（`/plugins?tab=skills`）。继续使用已有目录接口和安装关系，不创建新的技能存储。

支持检索、获取、理解与质检、整理与转换、分析、成果整理六种流程分类，并可与领域、发布来源、仅看已添加和关键词组合筛选。关键词覆盖标题、包标识、精确版本、说明与触发词。切换筛选回到第一页；不同版本独立展示，安装仍使用原有精确技能 ID。

卡片显示标题、分类、领域、版本和“尚未验证”。详情补充包标识及 SHA-256，已发布版本不提供编辑/保存按钮，延续后端不可修改的发布规则。此处“尚未验证”表示没有运行验证凭据；不把格式校验或官方来源当成验证通过。

旧版技能没有可信分类时保留为“未分类 / 旧版技能”，不根据名字猜测。当前本地目录的两条记录均为旧版；选择其他分类会真实显示无匹配，不生成演示技能冒充已安装内容。领域选项来自实际目录。

本轮是 LAB-09 的目录入口，不代表输入兼容性检查、技能执行验证或独立仓库贡献流程已经交付。下一步应提供可复现的通用技能包与贡献模板，再接入数据输入兼容性说明和对话选择。

验证：前端类型检查、生产构建、2,674 项测试通过；后端 5,375 项通过、32 跳过、190 子测试通过，继续排除原有含导入时外部数据库操作的 `test_admin_skill_delete.py`。Compose 配置通过；沙箱仍因 PyMuPDF、python-pptx 和原生 GRIB 依赖产生 3 项收集错误。浏览器核对了本地旧版记录展示、分类空结果和重置；固定版本及验证状态使用合成组件测试验证，不向用户目录写入测试记录。
