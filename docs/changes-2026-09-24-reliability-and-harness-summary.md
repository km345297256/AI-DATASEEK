## 1. 数据可读性与执行恢复

- 受管数据使用不可变、版本化的执行快照，准备及挂载前按实际沙箱用户验证可读性；旧任务和原始缓存不因新任务而改写。宿主路径继续经过 allowlist、链接／特殊文件及源变化检查。
- 执行账本区分未派发、确认零写入和副作用未知；零命中仍是失败，但可在确认没有副作用后纠正参数，不能将插件或模型自报当成恢复权限。
- 当前请求范围独立传入执行路径，用户请求摘录与事实证据分离，计划和未来研究目标不能自动扩大本轮授权。
- 平台只准备可信工作区下的固定 `output` 目录，检查链接及可写性；不自动创建任意输入／工作目录，只读预检不变成写入。
- 程序诊断绑定真实版本、原输入及错误证据；读取、改写或重命名本身不证明分析取得进展，未知执行不自动重放。
- 第一方文档工具优先暴露 PDF/DOCX 正文提取能力，元数据检查不再被当作可直接回答正文问题的证据。

## 2. 回答构建、科学性和最终发布

- 将有据正文构建、引用纠正、公开路径处理和冻结候选核验分开；主机编号后，独立检查最终文本的科学性及原问题覆盖。
- 若纠错或安全渲染改变候选，旧核验结果失效；审核不得返回替换正文、执行工具或通过重复请求争取肯定结果。
- 强化报告正文、纯文本科研回答、完整程序方法证据及上下文容量处理；不把文件存在、保存的代码或程序成功等同于科学结论正确。
- 区分技术不可用、证据引用拒绝、科学性否定、覆盖不完整和真实交付缺失；撤回全部正文不算成功。
- 科学斜线记法、单位及数字运算不再机械等同于文件路径；真实私有路径、未知文件引用、路径穿越和模糊身份仍拒绝发布。
- 协议／Schema 恢复使用冻结输入和一致结构，只进行有界只读纠正，不扩大执行权限；历史解释必须使用同范围、已审核、版本冻结的历史结果，不能证明本轮新计算或当前文件可用。

## 3. 工具调用、Shell 输出及 MCP 图片

- 派发前校验整批工具调用身份；缺失身份在请求副本中补齐，重复／冲突及缺失结果明确处理，不改写持久历史、不伪造成功观察。
- Shell 提供有界 UTF-8 预览、独立输出身份及分页游标；清洁／原始日志保存在沙箱生命周期内的私有临时缓冲。输出超限明确标注，观察者不会相互消耗游标，旧游标不能读取新命令。
- 确定性工具需要完整 stdout 时，只读补齐输出再解析，不重复执行原命令；这些容量边界不是任务累计配额。
- 可选 MCP 图片经过 MIME、base64、帧数和尺寸校验，规范化后存入 owner/session 隔离的私有 spill，请求前重新鉴权并展开；公开事件与持久记忆不含图片字节或内部文件身份。
- 图片支持要求显式开关、可用 spill 和精确模型能力声明，示例配置默认关闭；不获取远程图片 URL，不自动替换模型或密钥。
- 补充 DeepSeek 工具图片的请求级投影，保持不可信观察身份、工具批次顺序及预算关系，不修改持久消息。

## 4. 提交确认、长会话和恢复状态

- 输入请求在控制器内保留固定 ID、时间戳和载荷，区分明确拒绝与提交结果未知；新增 owner-only 只读接收核对接口。未观察到请求不等于服务端拒绝，不按相同文字合并有意新输入。
- 未确认提交的草稿和附件保留在内存，不写入浏览器存储；恢复沿用原身份，避免重复执行。
- 会话工具／步骤及展示摘要采用增量索引；历史前插后重建必要索引，按消息 key 和偏移保持阅读位置，用户主动滚动及卸载时清理锚点和观察器。
- 可信账本证明同一步骤、程序与参数后续成功时，旧记录显示“执行失败，后续已恢复”；保留失败详情，不改变整项任务和交付的真实状态。

## 5. SVG 验收与持久化兼容性

- 新增静态 SVG 结构安全检查与离线渲染验收，覆盖生成的 Matplotlib 图、恶意和空白 SVG；支持有限绘图 CSS，不承诺任意浏览器样式或外部资源。
- 原文件字节和摘要不因验收内部规范化而改变；缺失、损坏、不安全和未支持文件保持独立失败，不以存在性代替内容核验。
- 冻结六个持久化根的读写 Schema、版本及摘要，追加兼容性记录和旧样本回读／回放测试。检查纳入 pytest 与回归入口，不通过覆盖旧快照消除差异。
- Schema 门禁仅验证结构，不能替代语义、权限与科学证据审核。新增版本及兼容读取仍须按实际变化登记。
