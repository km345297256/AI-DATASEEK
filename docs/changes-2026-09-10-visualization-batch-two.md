# 科学数据可视化第二批：按需信号窗口、地理格式、显微切片与归档成员

日期：2026-09-10。承接[第一批](changes-2026-09-10-visualization-batch-one.md)。

## 本批范围

增加 5 个可独立启停的 Cordis 插件，目录由 40 增至 **45 个**，批准适配器由 39 增至 **44 个**。公共协议仍为严格整数 `contract_version: 2`，使用既有统一调用入口；新增 `window` 输入预算语义和 `features` 结果类型，不另建业务接口或通信层。

| 插件 | 实际支持范围 | 主要限制 |
| --- | --- | --- |
| EDF/BDF 通道时间窗 `viz-edf-signals` | EDF、EDF+C、BDF、BDF+C 连续生理信号；相对时间轴，分通道、分单位、原采样率 | 源 ≤8 GiB；每窗累计 ≤8 MiB、≤128 次范围请求；≤8 通道、≤60 秒、总计 ≤16,384 样本 |
| MCA 能谱 `viz-mca-spectrum` | 带 PMCA/DPPMCA/AMPTEK 标识的 ASCII 单谱；原始整数 counts | 输入 ≤4 MiB、≤8,192 通道；不拟合、不扣背景；只有明确单位与有效双点线性标定才显示能量轴 |
| 地理格式 `viz-geoformats` | ESRI ASCII Grid `.asc`、Surfer ASCII DSAA `.grd`、受限 KML 2.2 | 输入 ≤16 MiB；网格源 ≤1,048,576 单元、预览 ≤128×128；KML ≤512 要素、≤16,384 坐标 |
| CZI 显微切片 `viz-czi` | 官方 Zeiss pylibCZIrw 6.1.0；单文件、显式 scene 0、C/Z/T 与像素 ROI | 整文件 ≤64 MiB；ROI ≤1024×1024；≤4,096 子块、单子块解码预算 ≤16 MiB；Gray8/16/32Float、Bgr24 |
| 归档文本成员 `viz-archive-members` | ZIP stored/deflate、未压缩 TAR 中用户主动选择的小型 UTF-8 文本 | 归档 ≤64 MiB；展开成员 ≤256 KiB；≤4,096 成员；每页 ≤200 行、每行 ≤1,024 字符；不递归、不落盘 |

插件页面：`http://localhost:7001/plugins?tab=renderers`。文件面板的“可视化”下拉框选择相应视图。新插件默认启用，可单独关闭；原插件的开关偏好、ID、默认优先级保持不变。归档目录插件优先级 40，新文本成员插件为 30，因此原“只看目录”默认行为仍保留，需手动选择成员预览插件。

## 兼容性与效率

- AgentLoop、PlanActFlow、SSE、FastAPI 主机和 Docker 数据隔离边界不变；可视化仍属于独立 Cordis 目录，不混入模型分析工具列表。
- `window` 表示本次实际取回的累计字节，而非把整个源文件加载进内存。EDF/BDF 通过宿主代理读取授权范围，worker 不知道文件路径、文件 ID、用户或凭据。
- 文件、插件 ID/版本稳定时，目录轮询重建描述对象不会重复读取；用户修改通道、时间、坐标系或 ROI 后，点击按钮才请求新结果。
- EDF/BDF 各通道使用相同请求时间范围、独立纵轴与原单位，不将不同采样率数据重采样到同一个数组。单点窗口使用点标记，不显示空图。
- CZI 首次只检查结构，不自动解码像素；随后明确选择 C/Z/T 与 ROI。CZI **尚不是范围传输**，每次仍在整文件预算内取回输入，再解码选中区域。
- 前端已有本地 Plotly/OpenLayers 负责绘图，复用按需加载；不新增公网底图、CDN 或模型调用。
- 不声称这些改动已加速所有 Agent 分析。效率收益主要是长记录按需读取、显式选择和避免重复下载；常规分析流程保持原实现。

## 数据语义与安全适配

### 信号

独立按 [EDF/EDF+ 规范](https://www.edfplus.info/specs/edfplus.html) 与 [BioSemi BDF 规范](https://www.biosemi.com/faq/file_format.htm) 实现有界固定记录读取；**没有把 PyEDFlib 当作运行时依赖，也没有使用其要求本地整文件的读取 API**。

校验文件头、记录长度、16/24 位有符号数字值、物理标定与实际窗口样本数量。禁止不连续 EDF+D/BDF+D；同为 `.edf` 后缀的 ESRF 衍射图像不属于此插件。患者/记录身份、绝对日期、transducer/prefilter、注释文本不返回；注释与状态通道不可作为波形读取。连续性只来自文件头声明，不宣称已验证注释时间轴。仅用于数据探索，不用于诊断。

### 地理与显微图像

ASC/DSAA 不内置可靠 CRS，未明确选择时只显示本地像素坐标热图；仅根据用户确认的数据说明接受 EPSG:4326 或 EPSG:3857。DSAA 保留 node 注册语义并校正半像素外边界；NoData 透明、行序转换明确。不是对所有 `.grd` 方言的通用支持。

KML 只转换经过验证的 Point/LineString/Polygon；删除执行与外联能力，不接受 DTD/实体、NetworkLink、任意 href、外部样式或动态脚本。KML 使用格式规定的 WGS84，不允许覆盖成其他 CRS。

CZI 使用 [Zeiss 官方 pylibczirw](https://github.com/ZEISS/pylibczirw)，新增锁定依赖 `pylibCZIrw==6.1.0`；本次锁定的间接依赖为 cmake 4.4.3、validators 0.35.0、xmltodict 1.0.4。官方库及其许可随安装包保留；若后续对外分发镜像，需按上游 LGPL 许可继续保留相应声明及履行分发义务。本机 arm64 / Python 3.10 已实测，不代表完成所有操作系统验证。

拒绝分卷、多场景、非支持像素类型及越界 ROI。灰度 PNG 对当前 ROI 做 min-max 显示映射，界面展示原值范围；BGR 转 RGB，不修改原数据。缺失覆盖区域可能按库默认背景为零，明确提示不能据此做定量缺失判断。图像显示缩放仅改变屏幕尺寸，不增加读取像素或伪造原分辨率；不返回原始采集 XML 或身份字段。

### 能谱与压缩成员

MCA 是参考 [PyMca 格式支持](https://github.com/silx-kit/pymca/blob/master/src/PyMca5/PyMcaIO/specfilewrapper.py) 的受控 ASCII 方言读取器，**未引入完整 PyMca/Qt/fisx，也不宣称支持所有仪器 MCA 文件**。没有明确有效标定时保留 channel 轴；安全整数之外的 counts 拒绝，不静默降低精度。

归档先验证整个有界索引，包括未显示页，拒绝危险路径、链接、重名、加密、异常比率等。成员 ID 派生自完整归档内容摘要、索引与逻辑路径；同字节副本可能产生相同 ID，该 ID 不是授权票据。每次仍按 file_id、owner、文件 version、插件开关和目录 revision 核验。

成员内容必须显式带首次目录返回的 version；允许 txt/csv/tsv/json/xml/yaml/yml/md/log/ini/cfg/toml 小型 UTF-8 文本，全部作为纯文本，不解析实体、脚本、HTML 或链接。ZIP 独立验证实际解压 EOF、长度和 CRC，防止中央目录声明大小截断后隐藏余量；TAR 仅使用已验证 offset 的内存片段，不伪称具备成员内容校验和。不产生提取文件，也不扩大原目录插件能力。

### 统一资源约束

新读取器只读、非共享预览；显式选项与最终结果必须一致，避免“结果结构合法但属于其他窗口”。所有路径继续满足数据集 allowlist 和只读挂载要求，浏览器不收到真实主机路径。

复杂解析在原有一次性 worker 内：无网络、无端口、无数据集/主机目录挂载、非 root、只读根；1 GiB 内存、1 CPU、96 PID、512 MiB 临时空间。Window 请求 50 秒期限、单次源范围读取 10 秒期限；取消和超时后，并发槽保留至底层读取及容器回收结束。Docker 不可用时不退回主机解析。
