# 科学数据可视化第一批增强

日期：2026-09-10。范围：高频格式增强、结构树、音视频、压缩包目录。

本批依据 [SciDB 文件格式差距分析](scidb-format-visualization-gap-analysis.md)实施，不重复引入新 Agent 框架。现有 Cordis 可视化目录从 36 项扩展到 40 项；统一协议仍为 `contract_version: 2`，39 个批准适配器键由一份规范生成三端副本。既有插件 ID、个人启停偏好、AgentLoop、PlanActFlow、SSE 与只读数据边界保留。

## 1. 已实现能力

| 类别 | 实际能力 | 明确边界 |
| --- | --- | --- |
| 高频容器识别 | 对 HDF5、NetCDF、MATLAB、TIFF 执行有界内容探测；普通 `.tif` 可识别 OME／Geo 标签；MAT v7.3 推荐 H5Web | 最多读取 64 KiB 元信息，不解码像素或数组；探测结果不是完整格式认证，不扩大插件权限 |
| HDF5／MAT v7.3 | H5Web 展示文件内目录、数值节点、曲线与热图切片；无可画数值时仍展示目录；切片绑定目录所读文件版本 | 最多 256 个目录节点／8 层；MAT 按 HDF5 存储维度展示，可能与 MATLAB 习惯顺序相反，不解释对象引用或执行代码 |
| GeoTIFF | OpenLayers 增加波段选择、采样数值色标、NoData 透明显示；切换复用已授权文件和 TIFF 对象，并保留地图视角 | 保留清单 64 MiB 输入与 1,600 万源像素上限；最多 256 波段、显示采样最多 1,024×1,024；仍只支持明确 EPSG:4326/3857 轴对齐栅格 |
| 结构树 | 新插件 `viz-structured-tree`：JSON、XML、YAML/YML；展开、折叠、预览节点搜索，原始数值文本保真 | 4 MiB 输入；源最多 4,096 节点、32 层，展示最多 256 节点、8 层；不是整个大文件的索引服务 |
| 视频 | 新插件 `viz-video-player`：MP4、WebM、OGV 原生播放、暂停、时间定位、时长和分辨率 | 64 MiB 整文件交付；编码必须由当前浏览器支持，无自动转码、无外部播放地址、无自动播放 |
| 音频 | 新插件 `viz-audio-waveform`：WAV、MP3、OGG 播放；受限 WAV 逐通道峰值包络 | 16 MiB 整文件交付；WAV 支持受限 PCM 8/16/24/32 位与浮点 32 位；压缩音频仅播放，不生成频谱或声压量化结果 |
| 压缩包目录 | 新插件 `viz-archive-directory`：ZIP／TAR 只读目录，声明大小、压缩大小、嵌套归档标记、每页 200 行与本页搜索；GZ/GZIP/TGZ 首流头元信息 | 64 MiB 输入、最多 4,096 成员、声明展开总量最多 512 MiB、压缩比上限 1,000；不解压、不预览成员、不递归扫描 |

高频格式增强不是替换原视图：NetCDF 地图和曲线的默认顺序保留；用户手动选择优先于自动推荐。HDF5 文件头不能单独证明其是 NetCDF4。共享预览不发起新增内容探测，原共享 TIFF 字节预览保留。

## 2. 协议与安全适配

- 只使用既有 `bytes / preview / prepare` 操作和统一 `VisualizationResult`；没有新增另一套预览路由或动态脚本加载协议。
- 新增 `tree`、`media` 场景标签；原 `structure` 继续表示分子结构场景，不混用含义。
- 结构树与归档使用新增批准 reader，通过现有无网络、非 root、只读根文件系统的一次性 Docker worker 解析，不在 FastAPI 主机执行复杂解析。
- 新插件只声明 `file:read`，默认可在本机原会话中使用，不自动开放共享读取。所有请求继续检查文件归属、当前启用状态、操作白名单、文件版本、目录代际及输入／输出预算。
- 内容探测返回受控枚举与证据标签，不返回原始 TIFF 描述、宿主路径或外部 URL。目录启停、切换文件、关闭窗口后的迟到响应不能重新挂载旧内容。
- JSON 拒绝重复键和非有限数值；大整数及小数保留源文本。YAML 仅解析结构，使用明确的 YAML 1.1 标量分类，不运行构造器，不支持锚点、别名、合并键、自定义标签。XML 拒绝 DTD、实体、外部引用和处理指令。
- ZIP/TAR 在分页前检查整个有界目录，拒绝越界路径、重复／冲突路径、链接、特殊文件和超限结构。GZIP 只读首流头，不校验压缩内容、CRC、ISIZE 或实际流数。
- 播放器、结构树和压缩目录接入同一取消与销毁机制；关闭媒体后停止播放、撤销 Blob，并释放波形画布。

新增直接依赖只有沙箱中原已锁定的 `PyYAML==6.0.3` 声明，不升级已有依赖版本。前端复用现有 OpenLayers、geotiff.js、H5Web 与浏览器媒体能力，没有另嵌入桌面程序或新的远程服务。

## 3. 数据分析效率改进

1. 先读取少量内容证据，减少 MAT v7.3 或普通 TIFF 误选读取器后的完整下载与失败；常见小 TIFF／MAT 头在一个 4 KiB 范围请求内识别。
2. 相同目录代际的定时轮询不会重新探测或挂载预览。修复 H5Web、Plotly、NetCDF/FITS 及本批新增组件的对象重建触发重读问题；回归中连续三次等价目录更新不再产生额外读取，并保留用户变量／切片选择。
3. GeoTIFF 波段切换复用一次已授权读取，只解码选中波段，显示大小有上限，不重复取回整文件。
4. H5Web 数值传递从不必要的 Float32 转换改为 Float64，并将后续切片绑定首次目录版本，避免额外精度损失及混用不同版本。

以上是具体操作与请求次数改善，不代表所有真实数据的加载速度都有固定倍数提升。当前音视频、归档、HDF5 和 GeoTIFF 仍有有界整文件交付阶段，尚未实现浏览器级大文件流式／瓦片／分块服务。

## 5. 使用方式

1. 进入插件管理的“可视化”页（`/plugins?tab=renderers`），按需启停“结构树”“视频”“音频”“压缩包目录”能力。
2. 在数据集的数据文件列表点击预览；同一文件有多个已启用视图时，在“可视化”下拉框切换。
3. HDF5／MAT 先浏览内部目录，再选择数值节点与切片；GeoTIFF 可切换波段；结构树支持展开和预览节点搜索；ZIP/TAR 支持目录翻页；媒体需主动点击播放。

停用只影响该可视化能力，不删除数据集、文件或分析结果；保留原有文本、下载及其它匹配视图。

## 6. 本批未宣称支持的内容

- RAR、7z、ZIP64、分卷／自解压 ZIP、加密 ZIP；TAR 全局 PAX、稀疏文件及含 `.` 路径段的归档。现有显式解包工具能力不等于新只读目录插件已经支持这些格式。
- GZIP 解压、`.tar.gz` 内部成员目录、压缩成员内容预览、递归归档扫描。
- 任意视频／音频编码、AVI 转码、长音视频按需流式读取或 MP3／OGG 波形。
- 任意 HDF5 对象、外部链接、虚拟数据集，MATLAB 对象与 cell 引用的完整还原。
- 任意 CRS、非规则网格、旋转 GeoTIFF、COG 全量瓦片服务、目录型 Zarr、大体积显微金字塔。

## 7. 下一批建议（需确认后实施）

优先做少量代表性领域试点，避免仅按后缀批量宣称支持。工具范围与原作者来源见 [SciDB 差距分析的 B 组清单](scidb-format-visualization-gap-analysis.md)。

1. **有界资源／窗口能力**：为长信号、COG、大 HDF5、压缩成员与后续目录型数据设计批准资源集、范围请求和版本边界，先闭环安全成员预览与一种科学数据窗口；不直接放大本批整文件预算。
2. **ASC／GRD／KML 已确认方言**：补充常见地理数据入口，复用现有地图与数值视图；先确认 CRS、实际结构和缺失值语义，不能将所有 GRD 当作同一种网格。
3. **EDF/BDF 生理信号**：通道选择、时间窗、真实单位、不同通道采样率、事件注释；以 [PyEDFlib](https://github.com/holgern/pyedflib) 为 reader 候选，复用现有曲线界面。先区分生理 EDF 与 ESRF 衍射 EDF；隐藏患者身份字段，不输出诊断。
4. **MCA 仪器谱**：先判定实际仪器格式，以 [PyMca](https://github.com/silx-kit/pymca) 为 reader 候选，提供道数—计数、已知标定下的能量—计数与多谱对比；不猜测标定或默认做定量拟合。
5. **CZI 显微图像单场景试点**：以 [libCZI](https://github.com/ZEISS/libczi) 等为候选，先限单文件、明确轴与一个 ROI／切片，复用显微界面；先验证桥接与压缩支持，多场景拼接、SCN 和金字塔读取等资源协议准备好后再扩大。

Origin 工程只读静态数据、Bruker 已处理谱、ProcSpec 光学谱可作为之后一批；`.ar/.zap/.zFTp`、IMA、SPC 等仍需真实样本和文件头确认，暂不按后缀直接启用读取器。
