# 表格基础质检

用于小型 UTF-8、逗号分隔 CSV 的结构、缺失值和重复行检查。输入必须是用户本次授权且执行环境可访问的文件；不自行下载、不读取其他目录、不修改原数据。

1. 确认用户选定输入。仅处理最多 4 MiB、10,000 行数据、256 列；超限或格式不符时说明原因，请用户选择子集或其他技能。
2. 通过 skill_read_script 阅读 scripts/profile_csv.py。使用现有沙箱执行工具，在沙箱内保存脚本并运行 `python3 profile_csv.py <输入文件>`。路径按执行工具规则安全传参；禁止将用户输入拼为 shell 命令。安装技能不代表获得执行权限，不能绕过工具准入。
3. 成功退出后读取 JSON，核对行数、列数和 input_sha256。执行失败不得把错误 JSON 当质量报告。将成功 JSON 保存为独立成果并交付；不要覆盖原始文件。
4. 向用户解释缺失值只指空字符串或纯空白，字面值 NA/null 不自动视为缺失；重复行按解析后的字段精确比较，计数不含首次出现。保留原列名，不猜测单位、数据类型、异常阈值或科学含义。
5. 报告只是质检阶段的结果，不能将整个分析任务标记为完成。若没有可用沙箱或未实际执行，应明确说明未执行。

样例见 references/sample.csv。贡献验证见仓库 tests；样例通过不等于任意输入适用，更不代表平台验证状态已经升级。
